# 编目：热写与梦

> 2026-10-13 初稿；**10-14 重写**：记忆文字只由当下的它本人写，显式归它、隐式归系统。前置：`events.md`、`archive.md`、`reading-room.md`、`association.md`。
> 原方案（书记员模型跑 ①～⑦ 流水线）作废，git 历史里有。

## 为什么改

**口吻决定认同度。** 它读到的记忆如果措辞像别人写的报告（第三人称、只有打包好的结论、口号式的价值观），就会隔一层：事实上认，口吻上不认（Claude 读 ASCM 记忆的自述，10-13）。不同模型写出的东西必然不同，所以：

- **凡是它日后会当"我的"来读的文字，都由它本人写**：它自己的模型 + 它的自述。
- **系统不产出任何它口吻的文字**，只做确定性的事：找证据、数证据、算强度、校验。

## 一、显式 / 隐式

| | 显式：它写 | 隐式：系统算 |
|---|---|---|
| 形态 | 文字，它说得出来 | 数值：激活度、强度、预期分布 |
| 内容 | 情节条目、事实、明说的规矩、印象、规律、经验、线索卷、实体卡 | 记忆强度（想起的频次与近因、有没有写感受、有没有后果）、规律的证据数与近因、"她该来没来"的预期 |
| 怎么来 | 热写、冷写 | 从事件和证据按规则算，不调模型（投影） |
| 怎么起作用 | 被 recall、被组装器放进上下文 | 决定哪条显式记忆什么时候浮上来、多强（`association.md`） |

- **对 LLM，隐式记忆没有文字形态**。人的条件反射、习惯化改的是神经；这里改不了权重，唯一能起作用的是"什么时候浮起什么"。系统永远不写"你对 X 敏感"，只让和 X 有关的那几条更容易浮上来。
- **例外：经验**。人的程序记忆是隐式的，LLM 没有"手熟"——会怎么做只能以文字进上下文，所以经验由它写，系统只在触发条件出现时推上来。
- **规律该多当真，它自己推**（10-14 晚）：敏感化 / 钝化 / 复发不另做数值，把规律和证据摆到它面前就够；隐式只管"摆什么、什么时候摆"（`reading-room.md` §二）。
- **两边可以对不上，对不上本身就是信息**：显式写"我不在意"，隐式里相关回忆一直在浮。这就是镜子与自述的对照。

## 二、热写：收尾时写情节

**什么时候**：压缩前、会话结束前。由身体（harness）控制时机——Soma 接管压缩，快到阈值时先让它热写，再压缩（`soma.md`）。

**写什么**：从上次热写到现在、这个会话里的一段，**一件事一条**：

- 第一人称，它自己的口吻；挂角标（档号），带时间、在场的人。
- 感受（原 imprint）写在条目里，跟着这件事走。
- 一件事一条是为了 recall：整块日记命中一次就是一大段，大半无关。随笔另写（`self.md` 日记），不承担 recall。

**视野只有局部**：只写上下文里有的——那才是它经历过的。日志里有、它当时没看到的（没注入的感知、不在场时到的信），不归它叙述。

**系统附一张清单**：这一段的事件，带档号，用经历投影的模板渲染。它从清单里引用；日志比上下文多的（大块工具返回）以日志为准，按档号调。

**判据**（考卷判内容，不判文风；不给范文）：
- 只用第一人称；不写自己的名字，不替自己定性别。
- 写具体的动作和原话；结论单独写，标明是谁、什么时候下的（"当时我觉得……"）。
- 对别人的定性（"她很失落"）同样标明是谁的解读。
- 次数、频率不写——那是统计。

**按重要性分配细节**（沿用原 ② 的判据，现在由它自己判断）：
- **意外**：看了上文就知道下文的——一笔带过；第一次、和预期相反、被纠正的——细写。
- **后果**：做了决定、改了东西、许了承诺、关系有变化、情绪强烈——细写。
- 一笔带过不是丢：原文在库房。

**改写**（10-14）：写错了、说法不对、后来理解变了，它可以改自己的情节——写一条新情节，`revises` 指向旧的；旧条留着，经历里显示新的，recall 只搜新的。只能改最新那版。人重讲一件事，原来的说法还在，只是现在讲的不一样了。（第一次接线测试里它自己发现情节里用「他」指代测试者，想改却改不了。）

**没写成**：
- 压缩前没写成、会话直接被关 → 事后用同一模型带 transcript 无头补写（还是它本人，只是不在原上下文里）。
- 它敷衍或不写 → 系统不替它补。这一段只剩原文：查得到，没有它的说法，褪得更快。不写的代价是真的。
**写错也是经历**（10-15 Joy）：记错 → 做错 → 后果，每一步都是事件，不靠闸拦在写之前。模型各有长短，一份提示词让所有模型行为一致做不到，也不该追求；错误留在日志里，后果去纠正，`revises` 链就是"我当时那样以为，后来知道不对"。
- **前提：后果得能回到它眼前。** 按能不能闭环看：
  - 能闭环——记错一件事实，她当场纠正；用错一条规矩，她的反应摆进冷写材料（`feedback`）。交给后果。
  - 不能闭环——**自我证实的错**：规律被写宽到不会再被反驳（argon 首跑把"深夜回单字 = 困了"写进"不耐烦"的结果里，以后深夜不追问，也就永远等不到反例，`evals/argon-run1.md`）。没有后果不等于不重要。系统不替它改，只保证查得到：原话在库房，证据和改写链在书架。
- 观察的是"哪类错在哪个模型上闭不了环"，不是给每个模型补一层闸。要不要为某类闭不了环的错加闸，等日志里攒出实例再定。

## 三、冷写：睡觉时整理

**什么时候**：它睡觉（`slept`）时，空闲才能睡（`self.md` §一）。花它自己的额度，没有免费的书记员。

**全局视野由系统给**。规律、经验、线索需要跨会话的证据，而且**结果往往后来才到**（她第二天的反应、那个做法到底有没有效），热写时拿不到。系统按规则从全局日志找候选，摆给它：

| 摆什么 | 怎么找（确定性） |
|---|---|
| 现行规律的新候选证据 | 规律关于的实体 / 话题 / 条件，在上次冷写之后的事件里检索命中 |
| 经验的待定结果 | 挂在线索卷上、结果未定的条目，其后续事件 |
| 线索卷的新碎片 | 卷关于的实体 / 话题命中的新事件 |
| 外部反馈（镜子） | 它的行为之后，她的回应、工具成败——**原样全给，不筛**；10-15：落成材料里的 `feedback`，机械配对、用原话、不受留意约束（`attention.md` §五） |
| 统计的变化 | 统计投影与基线的偏离；10-15：只给它 `track` 了的指标（`attention.md` §四） |
| 留意的新候选（10-15） | 它写的留意，按 `watch` 在新经历里命中 |
| 它没在场的事 | 不在任何热写段里的事件（睡着时的感知、单独一次心跳醒来） |

**它看完写回**：新规律（`semantic.proposed`）、印证 / 反例（`semantic.evidence`）、改写或作废、经验条目与结果（`lesson.*`）、线索卷（`thread.*`）、事实、实体卡与合并。

**系统不给结论，只给证据**。归纳成什么由它写；证据数、强弱、置信度由系统从档号数出来，不让它自评。

**镜子的防线**（Roy 把毛病美化成特色的教训）：
- 反馈原样全给，它可以判"无关"，判了留痕；跳过不看也留痕（积压可见）。
- 反例要指出是观察方式下的哪条事件；"好像不符合"不算。
- 浮现排序只从证据数、近因和结果算，它写的措辞改不动（写得再重，证据数不变）。

## 四、系统闸

- 引用的档号必须真实存在；热写的引用必须落在本段内；空证据拒收。
- 热写按会话记游标（上次写到哪）；冷写按全局游标。失败记系统日志。
- **考卷**：模型是它本人，不按工序换；换的是提示词（热写提示、冷写提示），用考卷验证（沿用 `durable_write_plan` 的"判据清单 + 独立考卷 + 系统闸"）。一个验证：给它两版叙述（自己写的 vs 别的模型写的），看它更认哪个、读完行为有没有差。

## 五、不做的

- **分场**（原 ①）：热写以"段"为单位，冷写按游标，分场没有消费方。`src/catalog/scenes.ts` 撤掉，git 历史里有。
- **书记员模型**、按工序配模型、替书记员调提示词。
- **日 → 周 → 月摘要阶梯**：还没有消费方。
- 新工序的准入：先说清消费方是谁、怎么评测。

## 六、从 ASCM 吸取的教训（仍适用）

1. 一道工序只产出一样东西——热写只写情节，冷写的每类产出独立评测。
2. 产出多、消费方少——每样产出都要有消费方。
3. 上游丢了、下游补——热写没写的不由冷写替它编。
4. 证据真实非空。
5. 先考卷后提示词。

## 七、原则：召回 = 还原处境，不是回答问题

普通记忆库的召回为回答问题服务。Psyche 的召回是为了**还原此刻的处境**，让 Agent 像一个连续存在的个体那样决策——角色真实连续，剧本是它自己的经历写的。

| 此刻要知道的 | 来自 |
|---|---|
| 我在哪、能做什么、在这里学会过什么 | 位置与处境、能力表、经验 |
| 谁在、我和他现在是什么关系 | 实体卡、规律、印象 |
| 正在发生什么、刚才发生了什么 | 近期经历、收件箱、感知 |
| 我挂着什么、答应过什么 | focus、线索卷（承诺线） |
| 我此刻什么状态、在意什么 | 自我状态、自己的提示词 |
| 以前类似的情况怎么样 | 情节条目（联想 / recall） |

两条路都覆盖全部投影：**系统拉**（组装器 + 联想，不由自主）和**它自己找**（recall + 馆藏地图）。
