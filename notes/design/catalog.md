# 编目（梦）

> 2026-10-13 定（初稿）。前置：`events.md`（梦类事件、投影原则）、`archive.md`（两段式经历）。
> 编目是 Psyche 里唯一进库房、唯一调用 LLM 产出记忆的地方。它的产出属于 Agent——不由自主，但是它的。

## 从 ASCM 吸取的教训（见 `../background/ascm-inventory.md` §四）

1. 一个调用产多样东西 → 改一样、其它一起漂，也没法单独评测。
2. 产出多、消费方少。
3. 上游丢了、下游补。
4. 推送层改得最勤、评测最少。
5. 一个症状加一个机制，很少撤。

## 一、什么时候做梦

- **Agent 睡觉（`slept`）时触发**。睡不睡、何时睡是它的 rhythm，自己定。
- **困（系统机制，压力不是强制）**：由身体的精力决定（醒着与处理 token 都在涨睡眠压力），见 `body.md`；不消耗也会精力过剩、睡不着。
- **手上有活不能睡**：harness 里有进行中的会话、或她正在跟它说话时睡不了，只会越来越困；空闲下来才能睡。真在干活时撂挑子——那也是一次表现，会留下经历。

## 二、流水线：一道工序只产一样东西，每样都有消费方

| 工序 | 产出 | 谁用 | 方法 |
|---|---|---|---|
| ① 分场 | `scene` | 档案目录、② | 先用规则切（时间间隔、换 harness），边界不清再问 LLM |
| ② 叙述 | 长期经历（带角标） | 组装器、recall | 每场一段，**按重要性分配细节**（见下） |
| ③ 实体 | `entity` / `alias` | whois、联想 | 只提名，合并由 Agent 确认 |
| ④ 语义 | `semantic.*` + 证据 | 阅览室 | 事实、规律、印象，必须挂证据（见 `reading-room.md`） |
| ⑤ 经验 | `lesson.*` | 组装器、联想 | 复盘：做法 → 结果，按触发条件归档 |
| ⑥ 线索 | `thread.*` | 组装器、recall | 归卷、判断状态（进展/反复/闭合） |
| ⑦ 敏感化 | `semantic.*`（后件为感受的规律） | 联想 | imprint 给感受，结果定强弱（钝化、分化、复发） |

依赖：① → ② → ③～⑦ 并行。②～⑦ 都可以同时读叙述与原始事件。

### 叙述：按重要性，不按原文长度

ASCM 的误区：按原文长度保情节，留下大量没用的口水情节。改为**重要的保细节，不重要的一笔带过**。目标是捂住上下文、讲清这一段明确发生了什么，不追求原话保真。

判据归成两条：
- **意外**：看了上文就知道下文的——不重要。第一次出现的、和预期相反的、被纠正的——重要。
- **后果**：产生实际效用（做了决定、改了东西、许了承诺）、关系有变化、引发强烈情绪——重要。

一笔带过不是丢掉：原文仍在库房，以后换更好的模型重新做梦还能挖出来。
这道工序最容易漂，考卷重点出。

## 三、系统闸

- 产出引用的档号必须真实存在、且在本批输入里；空证据拒收。
- **每道工序独立游标**：哪道失败只重跑哪道，失败记系统日志。
- **每道工序独立配模型、独立考卷**：换模型只换一道，用考卷验证（沿用 `durable_write_plan` 的"判据清单 + 独立考卷 + 系统闸"）。

## 四、不做的

- **日 → 周 → 月摘要阶梯先不做**：在 ASCM 里主要喂推送和 timeline，Psyche 里还没有消费方。哪块真需要再加。
- 新工序的准入：必须先说清消费方是谁、怎么评测。

## 五、原则：召回 = 还原处境，不是回答问题

普通记忆库的召回为回答问题服务。Psyche 的召回是为了**还原此刻的处境**，让 Agent 像一个连续存在的个体那样决策——说是角色扮演也行，只是角色真实连续，剧本是它自己的经历写的。

一次决策需要的东西散落在所有投影里：

| 此刻要知道的 | 来自 |
|---|---|
| 我在哪、能做什么、在这里学会过什么 | 位置与处境、能力表、程序记忆 |
| 谁在、我和他现在是什么关系 | 实体、语义、敏感化 |
| 正在发生什么、刚才发生了什么 | 近期经历、收件箱、感知 |
| 我挂着什么、答应过什么 | 自我状态（focus）、线索卷（承诺线） |
| 我此刻什么状态、在意什么 | 自我状态、自己的提示词 |
| 以前类似的情况怎么样 | 长期经历（联想 / recall） |

两条路，**都覆盖全部投影**：
- **系统拉（不由自主）**：组装器 + 联想，按上表组装处境切片送进来。
- **它自己找（主动）**：recall 跨所有投影查；外加一份**馆藏地图**，让它知道自己有什么、去哪找（ASCM 的 Agent 是"盲人"，无法鸟瞰全馆）。

细节留给组装器与门户的设计。
