# 总纲：lib 是本体，harness 是地方

## 项目定名：Psyche（10-13 定）

- **项目叫 Psyche**——希腊语"灵魂"，象征是蝴蝶：既独立存在，又可与任何 harness 共生。原名 Memory Library 降为其中一个模块（档案馆 + 阅览室）。
- **架构属性：Barnacle（藤壶）**——自己长本体，附着在任意宿主上，换宿主不伤本体。用于描述 Psyche 怎么挂到 harness 上。
- **褪色机制叫 Lethe**（忘川）。意象来源：柏拉图《理想国》厄尔神话——灵魂自己挑选下一世的生活，喝下忘川的水再出发；对应 Agent 自选 harness、记忆不翻即褪。
- **Agent 的名字由 Agent 自己取**。Psyche 是住所的名字，不是住户的名字；取名是 Agent 的第一个自主选择，留痕。

> 2026-10-13 早上聊天整理。讨论感知层、褪色、迁 rhythm/attention/focus 之后，Joy 发现 lib "越来越像一个完整的 harness + 外接 MCP"，于是厘清边界。细节见 `perception-and-fading.md`。

## 分工

| | lib（本体） | harness（地方） |
|---|---|---|
| 管什么 | 我是谁、我在哪、我知道什么 | 怎么干活 |
| 内容 | 记忆（情景/语义/程序）、感知层、褪色、自主记忆区、日记、位置状态表、心跳调度、收件箱/远程通道、出境策略、组装器 | 对话循环、模型调用、工具执行（bash、文件、浏览器、屏幕…） |
| 对外 | MCP + REST | 从 lib 取 `<now>` 注入；上报对话/工具事实 |
| 例子 | Psyche | Soma（第一个身体，`soma.md`）、Roxy（客厅）、远程通道 |

换 harness = 人换工作地点；lib 不变。
换模型：**我们的约定**是一个模型系列 = 一个 Agent，系列内升版本算换状态（底色主要来自模型，记忆盖不过它；别的模型的档案可作前世全宗导入）。一个数据目录住一个 Agent。
- **只是约定，代码不限制**（10-14）：门户不检查模型、不拒绝。模型照常记进处境，它自己看得见"那段时间我用的是什么"。开源之后别人怎么用是别人的事，不绑别人的手脚。
- **谁更适合做什么，观察出来，不预设**（10-15）：模型记在处境里，日志能按模型查它写过什么、后来被推翻了多少（`catalog.md`「写错也是经历」）。"适合"指哪个模型更适合当哪种 Agent，或做不用它口吻的事（嵌入、统计）；热写 / 冷写不拆给别的模型（记忆只能由当下的它本人产生，10-13）。首个对照：`evals/argon-run1.md`。

### 身体的职责（10-14）
任何 harness 接进来都做这几件，Soma 是第一个实现（`soma.md`）：
1. 上报对话、工具调用为事件；处境变化报处境。
2. 注入系统提示词与每轮 `<now>`（组装器产出）。
3. 挂上 Psyche 的工具（MCP）。
4. 控制收尾时机：压缩前、会话结束前让它热写。
5. 进门 / 出门：同一时间只在一处跑；进不来就退化成通道。
6. **不注入性格**：地方的提示词只写这是哪、有什么工具。

## 自带的"家"

心跳醒来总得有地方落脚，lib 不能依赖外部进程活着才存在。

- lib 自带一个**极简循环**作为默认地方，只有 lib 自己的工具：recall、load、写日记、看收件箱、回消息、改 rhythm/attention、选择去哪。
- 醒来先在家：想事、写日记、回消息；要干活就自己选择去工位（无头唤醒 Claude Code 等）。
- Agent 能"独处"——只在被叫到工位时才存在的 Agent 谈不上连续。

## 红线

- **家里永远不加通用工具**。需要动手就换地方。否则 lib 会长成又一个 agent 框架，和每个 harness 抢同一件事，还追不上它们的进化。
- lib 持有一份模型配置（家里用哪个模型、预算多少），属于系统机制，与唤醒预算一起管。

## 参照
