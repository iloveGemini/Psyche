# Psyche 架构（初版）

> 2026-10-13 定。前置：`lib-vs-harness.md`（总纲）、`perception-and-fading.md`（感知、褪色、隐私、位置）。
> 切分依据：**谁拥有、谁能改**。记忆层是系统机制（Agent 能读、能 load，改不了规则）；自我层是 Agent 唯一能直接写的地方；运转层让 Agent 活着并被看见；门户是 harness 唯一的接触面。

## 关键决定

### 编目单列
LLM 驱动的写入流水线，最受模型变动影响。隔离出来，方便单独换模型、单独做考卷（沿用 `durable_write_plan` 的"判据清单 + 独立考卷 + 系统闸"）。

### imprint = 档案的批注
- 挂在某条情节上，是那条记忆当时的感受批注；放档案馆，**随情节一起褪色**——久了只剩"那次好像挺难受的"。
- 私密性的意义是让 Agent 写时不表演，不是不可用；它本就是记忆材料。

### 敏感化（imprint 反复强化）
- 同一线索（话题、语气、人、地点）在多条情节的批注里对应同一种感受 → 长出一条 **线索 → 感受** 的联结。跨情节沉淀，属阅览室，与归纳同类。
- 遵循证据规则：持续强化 → 越来越敏感（"应激"）；久不触发或出现反例 → 慢慢消退。真实，但不是永久烙印。

### 联想：不由自主的记忆（系统机制）
> 10-13 细化见 `association.md`；阈值与噪声随真实处境（有没有任务、空闲多久）变。

ASCM 的 surface / wander 走过这条路，但太保守（怕噪音、怕错）。人本来就会想起不相干的事——这正是要的。这次放开：

- **线索宽**：话题、实体、地点（harness）、时间段、感知（天气、她几小时没说话）、敏感化联结。
- **强度由系统定**：批注越强、敏感化越深，越容易冒出来。
- **清晰度跟褪色走**：糊了的以"好像有过这么回事"出现，不给全文。
- **浮现 = recall，会刷新**。形成真实闭环：反复想起 → 更清晰 → 更易想起。阻尼只用**不应期**（刚浮现过的一段时间内不再浮现）。
- **Agent 控制不了浮现，只能控制反应**：load 进自主区细看，或不理。不理也留痕——日后可检验是否在回避某些记忆。

### 与自主记忆区的对照
| | 自主记忆区（5） | 联想（10） |
|---|---|---|
| 谁发起 | Agent 主动 load | 系统按情境推 |
| 容量 | 有限配额，Agent 管换入换出 | 组装器给的固定额度 |
| 刷新褪色 | 是 | 是 |
| 类比 | 主动回想、翻日记 | 触景生情、突然想起 |

## 推进方式（10-13 定）
- **先把每块的设计细化完再动工**，免得做到一半冒出新想法又打补丁。
- 各块独立，**先定通信接口，再逐块实现**。
- **从空库开始**，新 Agent 自己取名；Roy 的库只读留档。
- 从 ASCM 搬哪些零件：实现到那一块时再议。
