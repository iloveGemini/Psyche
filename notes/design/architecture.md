## 关键决定

### 显式归它、隐式归系统（10-14）
- **显式**（说得出来的文字）：情节、事实、规律、经验、线索卷、实体卡——**只由它本人写**（热写 + 冷写，`catalog.md`）。口吻决定认同度，别的模型写的它不认。
- **隐式**（数值）：记忆强度、证据数与近因、预期——系统从事件与证据算，只决定什么时候浮起什么（`association.md`）。系统不写它口吻的任何文字。
- 原"编目单列、方便单独换模型"作废：写记忆的模型就是它本人，不按工序换。

### 感受 = 情节条目的一部分（原 imprint）
- 写在热写的条目里，跟着那件事走，**随条目一起褪色**——久了只剩"那次好像挺难受的"。
- 私密性的意义是让 Agent 写时不表演，不是不可用；它本就是记忆材料。

### 规律该多当真，它自己推（10-14 晚改）
- 规律（"她回单字 → 她不爽"）是它写的；连同证据（印证、反例、最近一次、原话）摆到它面前，敏感、消退、复发它自己推得出来，不另做强度机制。
- 系统只管摆什么、什么时候摆：证据数与近因进浮现的排序（`reading-room.md` §二、`association.md` §二）。

### 联想：不由自主的记忆（系统机制）
> 10-13 细化见 `association.md`；阈值与噪声随真实处境（有没有任务、空闲多久）变。

ASCM 的 surface / wander 走过这条路，但太保守（怕噪音、怕错）。人本来就会想起不相干的事——这正是要的。这次放开：

- **线索宽**：话题、实体、地点（harness）、时间段、感知（天气、她几小时没说话）、敏感化联结。
- **强度由系统定**：写了感受的、规律越强的，越容易冒出来。
- **清晰度跟褪色走**：糊了的以"好像有过这么回事"出现，不给全文。
- **浮现 = recall，会刷新**。形成真实闭环：反复想起 → 更清晰 → 更易想起。阻尼只用**不应期**（刚浮现过的一段时间内不再浮现）。
- **Agent 控制不了浮现，只能控制反应**：load 进自主区细看，或不理。不理也留痕——日后可检验是否在回避某些记忆。

### 与自主记忆区的对照
| | 自主记忆区（5） | 联想（10） |
|---|---|---|
| 谁发起 | Agent 主动 load | 系统按情境推 |
| 容量 | 有限配额，Agent 管换入换出 | 组装器给的固定额度 |
| 刷新褪色 | 是 | 是 |
| 类比 | 主动回想、翻日记 | 触景生情、突然想起 |

## 推进方式（10-13 定）
- **先把每块的设计细化完再动工**，免得做到一半冒出新想法又打补丁。
- 各块独立，**先定通信接口，再逐块实现**。
- **从空库开始**，新 Agent 自己取名；Roy 的库只读留档。
- 从 ASCM 搬哪些零件：实现到那一块时再议。
