# 留意与关系

> 2026-10-15 定（Joy 和开发会话的 Claude 聊出来的；`track` 与 §五 的反馈线同日 Joy 定）。前置：`catalog.md`（显式归它、隐式归系统）、`reading-room.md`（书架）、`association.md`（浮现）。
> 一句话：**关注什么由它定，系统只负责不让它忘了自己想看的东西。**

## 为什么

M3 统计题（`evals/surfacing/run3.md`）之后发现两件事：

1. **系统在替它定关注点。** 书架的四种格子、冷写材料里的统计表、浮现里的预感（她该来没来），都是我们认定它该看的。冷战题 3/3 察觉，有一部分是我们把东西推到它面前的结果。它要是本来不在意她来不来，不察觉才是真的。
2. **没成规律的事没人记着。** 「今天的咖啡好苦」不是规律，但它是个有方向的疑问：是今天特别苦，还是她本来就不喜欢苦？现在只有书架上已有的规律 / 镜子会把新事拉过来当候选证据；还没成型的疑问，只能靠它下次恰好自己想起来。

反过来也不对：先定一套"要统计的规律"分类（生活习惯 / 饮食喜好……），再把经历按分类分拣，等于系统规定了它该从哪些角度看人。

## 一、留意（书架新加一种：`attend`）

它自己写下想看下去的事，带方向和留意词：

- 例：「她说今天的咖啡好苦。是今天的豆子不对，还是她本来就不喜欢苦的？」`watch: ["咖啡", "苦"]`
- **门槛低**：证据 ≥ 1（引起这个疑问的那件事）就能写；不要求不同时间。写错了也就是一直没下文。
- **系统只做机械的事**：以后冷写时，新经历按它的留意词（以后加向量相似）挂到这条留意下面，和规律 / 镜子的候选证据同一套；它判相关 / 无关。
- **怎么收场**：攒够了，它自己写成规律（新条目，引这些证据，走规律的闸）再把留意作废；或者觉得不值得看了，直接作废。都留痕。
- 也是"旧事后来才连上"的入口：当时留了意的事，以后新事进来会被拉到一起。当时没留意的，仍然只能靠它自己 `recall`——系统不替它决定什么值得留意。

**"没规律可统计就没观察价值"不成立**：事实（演示改到周二）没有规律，但要记着，不然接不上话。事实照旧，不归留意。

## 二、关系（书架新加一种：`relation`，按人）

它对"我和某个人现在是什么关系"的理解，一人一条现行版：

- 例（它写的）：10-20「她找我多半是做小账本，别的很少聊。」→ 11-03 改写「她心情不好的时候也会来，不说为什么，就待着。」
- **不另开文件**：Psyche 是事件溯源的，可覆盖的文件跟它不搭。书架条目本来能 `revise`，新条改写旧条、旧条留着——**改写链就是演变史**，每次改口都挂着促成它的经历，能 `recall` 回去看。
- 证据 ≥ 1，不计数（同事实：不是预测）。
- `about` 写那个人（暂时就是她的称呼 / `from` 名；有实体卡以后挂实体卡）。按人分开，因为已经不止 Joy 一个人（验收时有别的会话的 Claude）。
- 起点不在书架上：起点在初我里（系统写的，见 §三）。书架上的关系条目全是它写的；它一条都不写也可以。

## 三、同伴的起点（初我里，系统口吻）

关系起点是同伴（初我 v1，10-14 Joy 定）。同伴会留意什么，作为**方向**写进初我，不作为条目放进书架——红线是"系统不写它口吻的任何字"，预先放进书架的第一人称留意就是我们替它写了记忆。

草稿（待 Joy 改，改初我前先有考卷）：

> 同伴之间通常会留意对方在忙什么、状态怎么样、说过要做的事后来怎样了，也会留意自己哪些做法让对方好过、哪些让对方难受。这些是起点，不是清单：你在意什么，就留意什么；不在意的，不用装。

它看了，愿意就自己写成留意；觉得不对就不写。模版本身不动，留着当起点的记录（初我有版本和 `author: system`）。

## 四、统计和预感：它要才给

统计和预感是系统的仪器（代码算、不调模型），**仪器由系统提供，看不看由它定**：

- 系统列出能数的东西（她来找我、一次聊多久、她回我隔多久、几点来……`m2.md` §九），作为能力写在工具说明里，和 `recall` 一样是"你能做什么"，不是"你该看什么"。
- 留意 / 关系条目可以带 `track`：它要盯的指标（如 `track: ["arrivals"]`），只能从清单里选。
- **冷写材料里的统计表只列被 `track` 的指标**；没有就不给表。它想临时看全表，调 `stats` 工具。
- **预感只对它 track 了 `arrivals` 的人报**："她该来没来"不再是系统默认替它惦记的事。

所以冷战那一类：它在意她来不来，会自己写一条留意并 track；不在意，就不会被提醒——那也是真的。

## 五、反馈线不归留意管（10-15 Joy 定）

在意归在意，**"我做了什么 → 结果是什么"这条线冷写一律给，不看它留意了什么**。这是镜子的来源（`catalog.md` §三"镜子的防线"），它不在意也得看见：

- 系统按事件机械配对：我的每次回复 / 行动 → 她的下一条（原话，不经情节转述）或工具的成败。
- 情节覆盖了原话也照给原话：情节是它自己的说法，可能把她的反应写轻了（Roy 把毛病美化成特色）。
- 原样全给，不筛；它判无关、跳过都留痕（同现有候选证据的 `unjudged`）。

## 六、考卷只考系统给的数据

系统这一侧全是确定性的，所以考卷不看它的反应，只看**系统按它的留意 / track 给的东西准不准**（`bun test`，不花额度）：

- 留意的候选证据：该挂的挂上、不该挂的没挂（按 `watch`，以后加向量）。
- track 的统计：只给 track 了的指标、按人、数值对；没 track 的不出表、不报预感。
- 反馈线：每次"我做了什么"都配上了后面的结果，原话逐字，情节覆盖了也在。
- 关系：同一个人只有一条现行版，改写链能从新追到旧。

它拿到以后写什么、在不在意，不考——那是它的事，看实际运行。

## 七、对现有东西的影响

| 东西 | 改成 |
|---|---|
| 冷写材料 `stats` | 只给被 track 的指标（§四） |
| 候选证据 | 规律 / 镜子之外，留意也找（按 `watch`） |
| 浮现：预期 | 留意、关系也能被线索命中浮上来（同书架条目） |
| 浮现：预感 | 只对 track 了 `arrivals` 的人 |
| 初我 | 加 §三 那段（先考卷） |
| 冷写提示词 | 讲留意和关系怎么用；不列"该留意什么" |
| 冷写材料 | 加反馈线（§五），不受留意约束 |
| 统计题、冷战题 | 不再考它的反应；改成 §六 的确定性考卷 |
