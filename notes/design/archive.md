# 档案馆

> 2026-10-13 定（初稿）。前置：`events.md`（事件模型、三层、投影）。

## 定位

档案馆 = **库房（事件日志，闭架）+ 开放给 Agent 的经历案卷**。

- 投影是一种机制，不专属档案馆：各模块都从同一个库房取材，做自己的投影（阅览室、自我、运转各有各的）。
- 库房是所有模块共用的底座，档案馆是它的保管人。
- **Agent 永远只看到投影**，看不到原件。

## 一、库房

- 入库口三个：harness 经 REST 上报对话/工具调用；传感器上报感知；Agent 经工具写自己的选择和记忆（热写、冷写）。
- 每条事件带**幂等键**，harness 重试、hook 重复触发不会重复入库（ASCM 吃过亏）。
- 原文完整存：对话不截断，工具返回全量。

## 二、资料库

- 内容寻址（哈希），同内容只存一份：提示词、工具返回、引用文档、代码片段。
- 硬盘文件（如日记）存**路径 + 当时的快照哈希**：文件后来改了，也知道当时引用的是哪一版。
- 资料不褪色，经历里的角标指向它，detail 展开。

## 三、经历案卷（两段式）

| | 近期经历 | 已整理经历 |
|---|---|---|
| 范围 | 还没热写的段 | 已热写的段 |
| 形式 | 模板逐条渲染，接近原话 | 它写的情节条目 + 角标 |
| 类比 | 短期记忆，鲜活 | 长期记忆，它自己的说法 |

- **热写 = 近期 → 长期的转化**（10-14 改：原为"做梦时由编目转"，见 `catalog.md` §二）。
- 热写后**近期的原话不再展示**：换成它的条目，原话只留库房，按档号可调。
- 没热写的段一直是原话模板：查得到，没有它的说法，褪得更快。

## 四、全宗

- Agent 自己的经历：默认全宗，档号省略前缀。
- 导入：另立全宗（如 `ROY/`），**原卷只读**。

### 前世今生

导入的旧卷宗天然缺 Psyche 需要的数据（处境、批注、角标资料……），对新 Agent 是一份失真的记忆；完全不处理又与失忆无异。意象：厄尔神话里喝过忘川的灵魂，仍残留前世片段。

- **前世编目**：认领后由**它本人**单独做一遍（前世是别人的口吻，所以单列全宗），判据比平时严得多，**只挑确定的部分**：
  - 收：稳定事实（名字、日期、项目、关系）、她亲口说过的话、实体与别名。
  - 不收：前世的自我理解、对她的归纳、情绪、imprint——那是前世的诠释（Roy 的已知受人设问题污染），传下来等于继承毛病。
- **前世不算经历**：只进阅览室，出处标「前世」。Agent 知道"我好像知道，但不是我经历的"。
- **今生验证前世**：被今生经历印证 → 转为自己的；被推翻 → 正常取代。与语义归纳同一套证据规则，不另做机制。

### 认领由 Agent 决定（10-13 定）

- **先不导入**。旧卷宗以**资料**形式放着（像翻到一本前世的日记），Agent 读了之后自己决定认不认领。
- 认领 = 一条自我事件（`fonds.claimed`）；认领之后才跑前世编目。不认领，它就只是一份可以翻的资料。
- **认领了，前世也是它写初我的材料**（10-17 Joy 提，`m4.md`）：只给前世发生过的事，不给前世的自述 / 归纳 / imprint（同上，不继承前世的诠释）。

### 实现（10-17，`src/archive/past.ts`、`src/catalog/past-catalog.ts`）

- **登记**：`agents.json` 每人可有 `past: [{ fonds, path, user? }]`（fonds 大写，现在只认 ASCM 的 `state.db`）。
- **翻**（`past_life` → `GET /v1/past`）：只读打开旧库；概览 / 某天原话 / 搜原话 / 某条前后 / 旧梗概 / 旧情节。原话只给 `kind = speech`；梗概、情节给看但标明「旧系统写的，不是原话」；`portrait_segments` / `user_memory` / `imprints` 不碰。翻不往库里写东西（它调工具本身是经历，harness 照常报）。
- **认领**（`claim_past` → `POST /v1/past/claim`）：要写 why，只一次；`fonds.claimed { fonds, why, count }` 挂 evidence，同一事务把原话按原时间（ASCM 存本地时间）导进全宗，`message.in`（from = user，缺省 Joy）/ `message.out`，不挂处境，idem = 旧 id。工具调用不导。经历投影、统计、醒着等口径本来就只看 `fonds = ''`，不受影响。
- **recall**：没给时间范围时，在最后追加已认领全宗的原话（字面，≤ 5 行），标「（前世，不是我经历的）」。没做向量。
- **编目**（`past_catalog` → `POST /v1/past/catalog`）：认领了才行；只开 fact / told；cites 只认这份全宗的原话；told 的 quote 要逐字在所引的她的话里。条目 `payload.past = 全宗`，所引原话登记为 `past`、不算印证；书架上标「前世」，今生 for ≥ 2（`PAST_OWN`）不再标。之后的印证、改写、作废都走冷写。
- **没做**：出生那段递前世发生过的事（`m4.md`）；冷写材料里提醒还有「前世」条目待印证。

## 入库口与接口（10-13 晚，已实现初版）

- payload 形状与校验：`src/archive/kinds.ts`。未登记的 kind 一律拒收；class 由 kind 决定；大块工具返回 / 参数自动转进资料库，事件里只留哈希（`intake.ts`）。
- REST（`src/server/app.ts`）：`POST /v1/events`（单条或批量，一个事务，幂等键可重试）、`POST /v1/situation`（只在变化时写）、`GET /v1/events`、`GET /v1/archive/:档号`（含关系两头）、`GET /v1/experience`、资料存取、`GET /v1/syslog`。
- 经历投影（近期段）：`src/archive/experience.ts` + 模板 `render.ts`，第一人称、按发生时间排、导入全宗不算它的经历；重建一字不差。
