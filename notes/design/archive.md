# 档案馆

> 2026-10-13 定（初稿）。前置：`events.md`（事件模型、三层、投影）。

## 定位

档案馆 = **库房（事件日志，闭架）+ 开放给 Agent 的经历案卷**。

- 投影是一种机制，不专属档案馆：各模块都从同一个库房取材，做自己的投影（阅览室、自我、运转各有各的）。
- 库房是所有模块共用的底座，档案馆是它的保管人。
- **Agent 永远只看到投影**，看不到原件。

## 一、库房

- 入库口四个：harness 经 REST 上报对话/工具调用；传感器上报感知；Agent 经工具写自己的选择；梦写整理结果。
- 每条事件带**幂等键**，harness 重试、hook 重复触发不会重复入库（ASCM 吃过亏）。
- 原文完整存：对话不截断，工具返回全量。

## 二、资料库

- 内容寻址（哈希），同内容只存一份：提示词、工具返回、引用文档、代码片段。
- 硬盘文件（如日记）存**路径 + 当时的快照哈希**：文件后来改了，也知道当时引用的是哪一版。
- 资料不褪色，经历里的角标指向它，detail 展开。

## 三、经历案卷（两段式）

| | 近期经历 | 已整理经历 |
|---|---|---|
| 范围 | 上次做梦之后的事件 | 已做过梦的事件 |
| 形式 | 模板逐条渲染，接近原话 | 编目写的分场叙述 + 角标 |
| 类比 | 短期记忆，鲜活 | 长期记忆，概括过 |

- **做梦 = 近期 → 长期的转化**。
- 做梦后**近期的原话不保留**：转成叙述，原话只留库房。像人睡一觉，记得的是那天大概发生了什么，不是逐字原话。

## 四、全宗

- Agent 自己的经历：默认全宗，档号省略前缀。
- 导入：另立全宗（如 `ROY/`），**原卷只读**。

### 前世今生

导入的旧卷宗天然缺 Psyche 需要的数据（处境、批注、角标资料……），对新 Agent 是一份失真的记忆；完全不处理又与失忆无异。意象：厄尔神话里喝过忘川的灵魂，仍残留前世片段。

- **前世编目**：单独一遍，判据比平时严得多，**只挑确定的部分**：
  - 收：稳定事实（名字、日期、项目、关系）、她亲口说过的话、实体与别名。
  - 不收：前世的自我理解、对她的归纳、情绪、imprint——那是前世的诠释（Roy 的已知受人设问题污染），传下来等于继承毛病。
- **前世不算经历**：只进阅览室，出处标「前世」。Agent 知道"我好像知道，但不是我经历的"。
- **今生验证前世**：被今生经历印证 → 转为自己的；被推翻 → 正常取代。与语义归纳同一套证据规则，不另做机制。

### 认领由 Agent 决定（10-13 定）

- **先不导入**。旧卷宗以**资料**形式放着（像翻到一本前世的日记），Agent 读了之后自己决定认不认领。
- 认领 = 一条自我事件（`fonds.claimed`）；认领之后才跑前世编目。不认领，它就只是一份可以翻的资料。
