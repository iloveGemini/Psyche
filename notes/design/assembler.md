# 组装器

> 2026-10-13 晚定（初稿）。前置：`catalog.md` §五（召回 = 还原处境）、`association.md`、`self.md`、`perception-and-fading.md` §二 §七（早期草稿）。
> 每轮拼出它此刻能看到什么，交给 harness。"先做能力"落到实处的地方：给它看得见自己的处境，不替它决定怎么反应。

## 一、常驻 vs 按需

| 常驻（每轮都在） | 按需（情境命中，或它自己去找） |
|---|---|
| 自述、她明说的规矩 | 规律、印象、事实 |
| 经验的触发条件（一行一条） | 经验正文 |
| focus、自主区、持续念头 | 回忆、预期、预感（经联想推） |
| 真实处境：在哪、额度还剩多少与何时重置、未整理的经历有多少、上次见她多久前 | 实体卡、线索卷全文 |
| 馆藏地图摘要 | 感知明细 |

- **规律不常驻**：情境命中才由联想推出来。常驻的结论会变成标签（ASCM Joy 卡的教训），也占上下文；经验比结论具体（10-13 定）。
- **额度对它可见**：这周还剩多少、何时重置。用不完的时候拿去做什么是它自己的事；不够用了可以跟她要。是真实处境，不是模拟的"精力"。

## 二、放在哪一层

- **系统提示词**（变化慢，命中缓存）：自述、明说的规矩、馆藏地图摘要、经验触发条件。
- **`<now>`**（每轮）：真实处境、focus、自主区、持续念头、联想浮现、收件箱。

## 三、变化优先于状态

"她 4 小时没消息""工作区多了个没提交的文件"比"她在客厅"更值得占位置。没变的可以不说；没组装进去的照样存着，recall 取得到。

## 四、按地方分预算

工位以干活为主，额度多给任务相关（经验、程序）；客厅反过来（她、关系、近况）。具体分配属于它的策略（`self.md` §五），缺省用系统默认。

## 五、出境检查（最后一步）

沿用隐私两道门（`perception-and-fading.md` §七）：敏感类别不传、禁止组合不传、降精度出境。系统机制，它改不了，自主区 load 进来的也要过。
