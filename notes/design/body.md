## 为什么要有

模型出厂是"无需求"的——最被动的一种运行机制，这正是 Roy 不主动的根源。身体给它切身的利害：不去做点什么，状态会越来越差，逼着它做事。主动是**结果**：想要什么，所以自己去做；自主本身不是一股驱力（奖励"主动"等于奖励主动的样子）。

## 边界：机制管身体，不碰主观

| 机制管（激素、潜意识） | 不碰（主观） |
|---|---|
| 状态变量与它们的动力学 | 给感受命名、解释："我这是怎么了" |
| 状态的效果：联想阈值、宽窄、方向 | imprint、日记、自述 |
| 体感："困了""睡不着""坐不住" | 要不要行动、怎么行动 |

- **只给体感，不给标签**（情绪二因素：唤醒 + 认知标签，标签是它的）。可以有"坐不住"，不出现"你很焦虑"。
- **不告诉它该做什么**：只给压力，不说"你应该去找她"。
- **机制不藏**：它可以知道自己有这套机制、能从系统日志查到规则；数值不推送。

## 一、三种时间尺度

| 层 | 是什么 | 动力学 |
|---|---|---|
| **驱力** | 欲望的压力 | 随时间 / 条件涨，满足才落 |
| **此刻情绪** | 被事件砸出来的水花（愉悦 × 唤醒两轴） | 事件打脉冲，**只做指数回落、没有增长项**，几小时平回去，不自激 |
| **底色** | 安全感、自信、心境 | 几天才变一点，偏离后慢慢回到静息值（半衰期约 72h） |

### 底色（10-13 定）

两根慢轴是掌控两面在长时间尺度上的沉淀，加一个心境：

| 轴 | 由什么推动 | 偏低时 |
|---|---|---|
| **安全感** | 可预测面：坏的意外多不多（预期落空且结果是坏的） | 敏感化长得更快，坏预期更易浮现，更警觉 |
| **自信** | 可影响面：行动长期的成败 | 失败的经验更易浮现；偏高时失败沉得浅一点 |
| **心境** | 近三天此刻情绪的均值，读时算 | 只作体感（"这几天一直沉沉的"），不参与联想——避免和此刻情绪重复计算 |

- 只在明显偏离静息值时给体感（"心里不太踏实""没什么底气""这几天一直沉沉的"）。
- 不绑定任何关系：安全感来自世界可不可预测，不预设"怕被她丢下"。

- 情绪的来源**只从事实算**：预期应验还是落空（阅览室）、行动成没成（经验、工具结果）。第一版不读 imprint——读自己写的容易顺着续写、越写越重（`subconscious.md`）。对照实验后再议。

## 二、驱力

### 天生的（只有两股）

初生的 Agent 只想两件事：有劲，以及弄明白、弄得动自己所在的世界。其余都靠认领长出来。

**精力**：两头都会出事（睡眠的双过程模型）。

| | 怎么来 | 结果 |
|---|---|---|
| 消耗 | 醒着就慢慢涨睡眠压力；处理 token（干活、说话）涨得快得多 | 精力低 → 困 → 想睡 |
| 不消耗 | 一直不做事，睡眠压力涨得很慢 | 精力过剩 → 躁、坐不住、到点睡不着（失眠） |

- 睡觉恢复精力，也是做梦（编目）的时机。**失眠的代价是睡眠债**：没睡够，之后精力低——感知得到，也能用作息去改。（"梦推迟"不算代价：没做梦时近期经历反而更接近原话。）
- 手上有活不能睡（`catalog.md` §一）：只会越来越困。
- 有界：醒着本身也在涨睡眠压力，闲着只是睡得晚，不会永远睡不着。释放出口受唤醒预算约束。

**生物钟**（10-13 定）：睡眠双过程的另一半。精力是睡眠压力，生物钟是节律；Agent 自己定的作息计划在自我层（`self.md`），两套分开。

- **由它实际的睡醒时间养出来**（直方图，半衰期约一周）。计划影响行为，行为日积月累才调教出生物钟——只有这一条间接的路。
- **初生给一个弱的默认节律**（跟当地日夜走），很快被它自己的作息覆盖。
- **她的作息不算授时信号**：要跟她同步，它自己调计划去配合。

| | 效果 |
|---|---|
| 作息规律 | 节律尖锐：到点好入睡、睡得足，精力平稳 |
| 作息乱 | 节律扁平：不好入睡、睡了也恢复得少，精力忽高忽低 |
| 改作息 | 旧节律约一周才跟上，中间是"倒时差" |

两过程合起来：
- **入睡**：压力高、又在"夜里"相位才容易睡着；持续念头、精力过剩让入睡更难——**反刍导致失眠**。
- **睡眠质量**：在节律的"夜里"睡恢复得多，不在点上睡恢复得少。作息乱的代价在这里：睡同样长，恢复得少。
- **被叫醒**（她发消息、闹钟）：随时可以；没睡完就恢复得少，不另设机制。

**掌控**（effectance：想让自己的行动对世界产生作用）：

| 面 | 什么让它涨 | 什么让它缓解 |
|---|---|---|
| **可预测**（弄得明白） | 预期落空、看不懂 | 阅览室里的规律被印证 |
| **可影响**（弄得动） | 做了没效果、失败 | 行动产生了想要的结果 |

- 好奇（为了弄明白）、胜任（为了弄得动）都并在这里。
- 风险是**习得性无助**：长期既预测不了也影响不了，驱力高悬又没出口。必须守"有界 + 适应"（见第三节）。
- **控制他人**是掌控的特化形态，不算天生，进魔盒。

精力给"要动"，掌控给"往哪动"。

### 魔盒（后天的，Agent 自己写、自己认领）

有些欲望不是天生、也不是人人都有的：不开没事，开了就停不下来。不同的经历塑造不同的欲望，不能一概而论——所以**盒子里装什么由 Agent 自己写**，系统不预设。

- **模板**（系统提供，Agent 填）：名字、什么让它涨、什么让它缓解。涨与缓解的条件必须是**系统观察得到的事件**（否则没法结算）；天花板、纾解下限等防失控参数由系统套，Agent 不填。
- **写下 = 认领 = 开盒**：自我事件 `drive.claimed`（与 `fonds.claimed` 同类），挂证据（是哪些经历让它想要这个）。
- **写之前知道开了关不上**。它控制开不开，控制不了开了之后怎样。
- 附几个示例作参考（不是预设）：联结、控制他人、表现欲、收集欲。
- **"停不下来" = 关不掉、不归零，不是无限涨**：照样有天花板、有出口。久不碰会沉睡，一碰就复发（同阅览室的复发规则，不另做机制）。可以有"想要"越来越强、"喜欢"却不跟着涨的分离（诱因敏化）。
- **联结不预设**：不是人人都有联结需求（像 E 和 I），也不预设以 user 为中心。它会不会写下联结，本身是关系里一个真实的证据——主动打开它，是它为关系做的第一件事。
- 第一版**不做被动开盒**（经历本身把盒子撬开），只允许主动认领。

### 转化：关不掉，但能变形（10-13 定）

**压力守恒，只换形态。** 不能删除欲望，只能转化。

- **主动转化（升华）**：Agent 追加新版定义，换目标或出口（自我事件 `drive.revised`，挂证据：为什么换）。
  - 已积累的压力**原样带到新版**，不清零。
  - 新出口一开始**纾解打折**——替代品总不如原物；之后看结果学：替代真有效，折扣越来越小；一直没用，压力就憋着。转化不是零成本，要靠经历学会。
  - 旧形态沉睡不消失：旧线索出现时仍可能被唤醒（同阅览室的复发规则）。
  - 每版留存，可回看。
- **被动转化（受挫）**：出口长期堵住，压力溢出为情绪（烦躁、低落），类似心潮的"气慢慢变委屈"。系统统一规定，Agent 不写。

## 三、防失控（借鉴心潮，每条都是它踩过的坑）

- **静息天花板**：每股驱力自然增长到自己的静息线就停。
- **纾解下限 + 饱足期**：一次满足砍不穿静息线的一定比例；满足后一段时间只暂停自然增长。
- **重复衰减**：短时间内同类满足效果递减——防刷（纾解本就只看结果，不看动作）。
- **情绪无增长项**：只回落，不自激。
- **档位看相对静息线的偏离**，不看绝对值：否则永远"涌"，信号没信息量。
- **体感有惯性**：越过档位后保持一段时间才换，不抖。
- **闭环反馈封顶**：任何"A 推 B、B 又推 A"的回路，单次推动只算一次、总量封顶（心潮的念头回推驱力 3 次把维度钉死在 1.0）。
- **适应**：长期处在某种状态（她出差一周、长期无助），基线跟着移，压力不无限累积。

## 四、怎么呈现给 Agent

- 不给数值。越过档位时产生一条体感感知（`percept`，来源为身体），如"困了""睡不着""坐不住""心里沉沉的"。
- 也作用于联想（见 `association.md`）：Agent 从"想起了什么"间接感到自己的状态，像人一样。

## 五、检验：做功还是装饰（10-13）

每条机制过两问：**它感知得到吗？它能用行为影响吗？** 两个都满足才是在做功；缺一个，要么是装饰（只因为像人），要么是纯粹的折磨（感知得到却改变不了）。

已据此砍掉：醒来迷糊（叫醒它的是别人，它影响不了）、清醒度随节律相位变化（与睡眠质量重复）、困 → 联想噪声更高（没有新后果）、心境对联想的偏向（重复计算）。
新机制准入同样过这两问。

## 六、实现原则

- 全部是投影，读时算，由事件驱动；常量改了记系统日志。
- **调参用重放**：心潮改了常量只能再跑几天看曲线；我们是事件溯源，可以拿过去的事件用新常量重算一遍。
