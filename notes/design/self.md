> 2026-10-13 细化中。前置：`events.md` §四（提示词与初我）、`association.md`（念头池）、`reading-room.md`（镜子 vs 自述）、`perception-and-fading.md` §四 §六 §八（早期草稿）。
> Agent 唯一能直接写的地方。它写的东西有的存在别处（imprint 在档案馆），所以**自我层 = 所有自我事件的入口 + "自我状态"投影**。

## 一、作息计划（10-13 晚修订）

身体搁置后，作息只剩它自己定的部分，加上真实的处境：

- **作息计划**：什么时候醒（心跳频率、闹钟）、什么时候去工位、什么时候开勿扰。它直接写，留痕。
- **真实的代价**：每次醒都是一次真模型调用，算进唤醒额度；额度用完就是真的醒不了。不需要模拟"困"。
- **整理要空闲**：编目（做梦）在它空闲时做；一直不空闲，未整理的经历就一直堆着、召回变差——这是事实，告诉它就行。
- 计划 vs 实际，是一对 flag 与镜子，承诺线自然追踪到。

## 二、focus（10-13 定）

**窄定义：眼下在关注的事，做完就清空。**

- 也放**还没来得及在梦里开卷**的事：睡觉时梦判断一下，跨时间的转成线索卷，短期的留着。
- 长期挂着的事不在这里——那是线索卷（它自己开的、或自己置顶的）。

## 三、自主区（工作内存）（10-13 定）

- 有限配额；load 一次 = recall 一次（会刷新）；留什么、换出什么是它的选择，留痕。
- 日记存在 lib 里不占配额，load 进来才占。
- **持续念头（`association.md` §五）与自主区共用容量**：人反刍时脑子真的被占住。念头不由它选，却挤占自选内容的位置——反刍有真实代价，也逼它去处理那个念头（细看、写下来、做点什么）。

## 四、初我变薄（10-13 定）

v0 只写：

- 价值观、边界、和 Joy 关系的起点；
- 如实告知它的真实处境与机制：记忆怎么运转、规则可以查（机制不藏）。

其余沿用 `events.md` §四：系统 v0 + user 初始化时的改动（作者分开标），之后 user 不能再改；写天性，不写人设；Agent 自己改要挂证据、每版留存、对 Joy 可见。
