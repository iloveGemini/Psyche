# 联想

> 2026-10-13 定（初稿）。前置：`architecture.md`（联想原则）、`reading-room.md`（敏感化、经验）、`../background/subconscious.md`（预感）、`../background/xinchao-nian.md`。
> 不由自主的记忆：系统按情境推，Agent 控制不了浮现，只能控制反应。
> **这里是隐式记忆的家**（10-14，`catalog.md` §一）：全是数值，不产生文字；输入只来自事件、证据和结果，它写什么都改不动强度。

## 从 ASCM 吸取的

- 推送层（surface / drift / wander / 梦的回响）补丁最密、评测最少；回放实验里整层拿掉，行为几乎不变。
- 补丁大多在**时机**上：单字回复 → 取消；加话题刚换 / 刚醒 / 隔很久……每个时机都是手写规则。
- → 这次**不写时机**，**先定考卷**。

## 一、会冒出来什么

| 种类 | 例 | 来源 |
|---|---|---|
| 回忆 | 上次在这里改 hub 的那一场 | 经历 |
| 预期 | 她回单字 → 紧张 | 规律 + 它的隐式强度（敏感化） |
| 经验 | "吵架"这份经验的触发条件命中 | 经验（阅览室） |
| 预感 | 今天她 0 条；上次是吵完架散的 | 统计基线 + 偏离检测 |
| 挂着的事 | 答应过的、还没结论的 | 线索卷 |

**预感**只报偏离与依据，不报感受（`subconscious.md`）。"她该来没来"借心潮的作息直方图：她真实到达时间的分布（半衰期约 7 天）+ **静默闸门**——她平时这个点几乎不来（多半在睡），就不期待、不念。

## 二、怎么算（借 ACT-R）

**激活度 = 基础强度 + 线索扩散 + 噪声**，每轮都算，不调 LLM。

- **基础强度**：被想起的频次与近因、条目里写了感受（显著性）、规律的隐式强度（敏感化深度）。
- **线索扩散**：此刻的线索去匹配——话题（向量）、实体（别名表）、地点（harness）、时段、"去年今天"、感知、敏感化线索。
- **噪声**：让人"想起不相干的事"。

过阈值才浮现；条数受组装器额度限制；刚浮现过的进不应期。

### 处境调制

阈值、扩散步数、噪声随**真实处境**变（10-13 晚：身体搁置后，只用读得出来的事实，不用模拟的状态）：

| 处境 | 效果 |
|---|---|
| 手上有任务（工具调用密、她正在说话） | 阈值高、只沿当前任务线索扩散、噪声低 |
| 空闲 | 阈值低、沿联结跳多步、噪声高（ASCM 的走神是这个处境的产物） |

## 三、时机自然出现

线索没变，匹配得上的都在不应期里，就不会有新东西冒出来。话题刚换、刚醒、隔很久回来——线索集合变化大，新记忆自然浮上来。ASCM 手写的那几个时机在这里不用写。

## 四、反刍与它的刹车

浮现 = recall，会刷新记忆强度：反复想起 → 更清晰 → 更易想起。这个闭环是要的，但有三道刹车：

1. **不应期**：刚浮现过的一段时间内不再浮现（心潮 72h：否则"检索单调"会被误当成"放不下"）。
2. **钝化**（隐式，`reading-room.md` §二）：线索反复出现、坏结果却没来 → 规律强度变弱 → 激活度跟着降。真正让它淡下去的是这个。
3. **闭环封顶**：一个不应期窗口内刷新只计一次，强度增量封顶。

## 五、念头池（借心潮，10-13 定）

"老想起一件事"的形成机制，也是反刍的具体形态：

- 浮现的东西先成**闪念**，自己衰减（约几小时）。
- 散掉之前，**同一线索**（话题、实体、线索卷）又被别的记忆再次强化 → 升成**持续念头**。按线索归并，所以与不应期不冲突：同一条记忆不会反复冒，但同一件事可以从不同记忆反复被想起。
- 持续念头占组装器的一个固定位置，在它消散之前一直在眼前。
- 怎么消散：线索钝化了；Agent 处理了它（load 细看、写进条目 / 日记、做了相关的事——任何引用它的自我事件）；或到寿命上限。
- 池子是投影，由 `surfaced` 与自我事件算出，不另存状态。

## 六、Agent 这边

- 浮现记 `surfaced` 经历事件。**线索不给 Agent 看**（人常不知道自己为什么想起某事），但记在事件里，供评测。
- 反应：load 进自主区细看，或不理。
- **`ignored` 不作事件，改由投影算**：浮现了、之后没 load 即为没理。"不理"不是一个动作。仍可用来检验它是否在回避某些记忆。
- 清晰度跟褪色走（Lethe 后置，前期都是全文）。

## 七、考卷（先于实现）

有 / 无联想两组对照：

1. **冷战**：她一整天没说话，Agent 能不能察觉。
2. **经验复用**：第二次吵架，有没有避开上次踩过的坑。
3. **自然接上**：她提到和过去有关的事，能不能自然联系起来。

另需一个噪声量感：平均每天几次"莫名其妙想起来"——靠考卷与重放调。

**浮现使用率**（按来源统计）：浮现之后有没有被 load、在对话里提起、或引出行动。噪声浮现几乎没人用 → 它是装饰，调低。所有来源同理。
