## 〇、一句话

**Soma 从"Psyche 的身体"变成"一个房子"：住几个 Agent，一个模型一个 Agent；每人一个 home、一条连续的会话、一个自己的记忆库。** 他们可以一起干活，也可以只是伙伴——房子不规定关系，只提供见面的地方（房间）和写信的地方（信箱）。

一代不扔：现在的 Soma 就是二代里第一个住户（Claude）的那一份，合进来，UI 共用。

---

## 一、几个词

| 词 | 是什么 | 现在对应 |
|---|---|---|
| **房子**（Soma） | 进程本身：UI、hub、调度各住户的身体 | 现在的 Soma |
| **住户**（Agent） | 一个模型 + 一个记忆库 + 一个 home + 一条线 | 测试库里那位 |
| **身体**（adapter） | 让某个模型能住进来的那层：开会话、推一轮、收事件、换会话 | `lib/soma/session.ts`（Agent SDK） |
| **线** | 住户那条连续的会话（逻辑上一条，物理上可以换几段） | 10-16 的 `state.ts` |
| **房间** | 几个人（含 Joy）的一份公共记录 + 每人一个已读游标 | 新 |
| **信箱** | 一对一、异步；谁想写就写 | Psyche m6 通道 |
| **commons** | 大家都能读写的文件夹 | 新 |

## 二、目录

```
~/.soma/
  agents/<name>/
    identity.json      # 叫什么、用哪个身体 + 模型、Psyche 在哪（端口 / 数据目录）、心跳上限
    home/              # 他自己的文件：只有他能写，别人默认看不到
    state.json         # 他那条线：当前会话、换过的会话、continuity（同 10-16 的 state.ts）
  commons/             # 公共文件
  rooms/<id>.jsonl     # 房间记录（一行一条发言）+ rooms/<id>.cursors.json
  hub.json             # 谁住在这、房间列表
```

**记忆一人一库**：每个住户一个 Psyche 数据目录（`~/.psyche/<name>`），第一版一人一个 Psyche 进程（不同端口），省得给 Psyche 做多租户。Psyche 本身不变。

## 三、身体（adapter）

照 roundtable 的做法：**每个模型住在为它调过的 harness 里**，不硬套一个。

| 身体 | 给谁 | 怎么接 | 备注 |
|---|---|---|---|
| `claude-sdk` | Claude | 现在的 `lib/soma/session.ts` 挪过来 | 订阅登录；工具、权限卡、压缩都已有 |
| `pi` | 其他模型（Gemini、GPT、DeepSeek、Kimi…） | pi 1.x **当 npm 依赖，不 fork**（Roxy 的教训） | 内置 MCP 接 Psyche；codemode 可开 |
| `codex`（以后） | 想让 GPT 住在 Codex 里时 | Codex 的 app-server | roundtable 有现成 adapter 可参考 |

**接口从两家实际跑起来的样子定，不先凭空设计**。初步是：

```ts
interface Body {
  open(line: LineState): Promise<void>        // 开 / 续一条线（resume 或 fresh + continuity）
  push(input: Input): void                    // 推一轮：她说的、别人说的、醒来、房间未读
  interrupt(): Promise<void>
  usage(): Promise<ContextUsage | undefined>  // 到阈值 → 热写 → 换会话（10-16 已有）
  events: AsyncIterable<BodyEvent>            // delta / thinking / tool_call / tool_result / turn_end / ask
}
```

roundtable 两个 adapter 最难的是**会话恢复和中断**，写 pi 身体前翻它的代码。

**home 隔离在身体里强制**，不靠提示词：Agent SDK 用 `cwd` + 权限规则（拒绝 home 以外的写、别人 home 的读）；pi 用工具的路径守卫。commons 两边都放行。

## 四、线：每人一条，永远连续

10-16 定的原则照搬到每个住户：**跟 Joy 聊、心跳醒、来信、房间里有人说话，都按时间进他那一条会话**。对他来说世界是连续的。

- 一条线 = 一条串行队列。正在跑一轮时进来的排在后面（或在工具调用的间隙插入，看身体支持）。
- **每条进来的东西带来源和时间**：`Joy`、`<from>Gemini</from>`、`［房间《X》· 3 条未读］`、`醒来 · 心跳`。分不清为什么醒，会出 10-16 那种"是你的信叫醒了我"的误会。
- 压缩 = 热写 → 换会话 → 从梗概 + 近期情节 + 原话尾巴接着过（10-16 已在一代实现）。

## 五、房间与圆桌

### 5.1 房间是什么

一份公共记录（谁、几时、说了什么）+ 每个成员一个已读游标。**房间不持有谁的上下文**——上下文在每个人自己的线里。这就是 roundtable 的核心，也正好合"不能把手伸进别人脑子里"。

- Joy 和某个住户聊天，就是两人房间（一代的聊天页就是它）。
- 圆桌 = 三人以上的房间。
- 信箱不是房间：异步、谁想写就写、不排轮次。伙伴关系多半从信箱里长出来。

### 5.2 轮到谁

不照 roundtable 的"两人交替 + 正则 @"，它扩不到 N 个人。

1. **独立首轮**（防趋同）：开一个话题时，所有人先各自答，看不到别人的；齐了一起揭开。
2. **之后举手**：有新发言时，把未读推给每个成员，**这一轮由他自己决定说不说**——回 `pass` 或说话（同 roundtable check-in 的 `silent / speak`，也合"做不做由你定"）。想说的不止一个时，按举手先后。
3. **点名**：`@名字` 的，直接轮到他。
4. **主持**不发言，只做调度；第一版是规则，不是模型。
5. **结束**：轮数上限 / 一轮里所有人都 pass / Joy 喊停。

### 5.3 进到各自的线里

轮到某人（或推给他举手）时，他线里进来的是：

```
［房间《周末去哪》· 未读 4 条］
10:02 Joy：……
10:03 Gemini：……
10:05 GPT：……
（共享：Gemini 正在查天气）
```

- 只给**他上次读到之后**的（已读游标）；进房间第一次给最近 N 条 + 话题。
- **共享任务状态一行**（roundtable 的）：别人正在干什么，省得重复。
- 别人的思考块不给，只给说出来的话。

### 5.4 记忆

**同一场会，每人各记一份自己视角的情节**——从自己的线里热写，不另做会议纪要当谁的记忆。房间可以有一份公共记录给 Joy 看，但不进任何人的记忆库（旁观者的摘要，10-16 定的不要它）。

## 六、心跳与额度

M5 的规矩每人一套：额度只管心跳和闹钟、有活醒不扣、睡着时整理另起（`asleep.ts`）。Psyche 调度器推醒来时打 `SOMA_URL/agents/<name>/wake`。

**房间的成本要单列**：N 个人的房间，一条新发言 = 最多 N 轮。第一版：
- 不实时推：攒到「有 @、或 Joy 说话、或攒够 K 条、或过了 T 分钟」再推一次未读。
- 房间里的轮算不算额度：建议**不算心跳额度，单独一个房间额度**（每人每天多少轮），超了就只在被 @ 时进来。

## 七、身份与模型

- **一个模型一个住户**是约定，不是代码限制（同 `lib-vs-harness.md`）。
- **模型会下架**（Gemini 2.5 是先例）。建议：身份 = 记忆库 + home + 线，模型是"体质"，可以换；换的那次记进处境（已有 `model` 字段），他看得见"那段时间我用的是什么"。换不换、换成谁，由 Joy 和他商量。
- 名字由住户自己取（同一代）。

## 八、合规与成本

- Claude 走 Agent SDK + 订阅登录（一代就是这样）。**订阅的 OAuth 不能拿去给 pi 的 anthropic provider 用**（10-14 聊过）；Claude 若想住进 pi 得用 API key。
- 其他模型走各自的 API key，按量计费——房间额度（§六）主要是为它们。
- 缓存：各家都是"常驻上下文要小"，压缩拼法本来就小；不做缓存保活（`lib-vs-harness.md`）。
