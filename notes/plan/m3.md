## 一、线索（每轮算，不调模型）

| 线索 | 取自 |
|---|---|
| 话 | 她这一轮的话 + 本会话最近几行；刚醒或隔了很久回来、这一轮没有她的话时，用上次和她对话的最后几行（人醒来先想起的是上次怎么散的） |
| 人 | 这一轮说话的人（`from`） |
| 地方 | 当前处境的 harness |
| 时段 | 现在是凌晨 / 上午 / 下午 / 晚上；"去年今天" |
| 静默 | 距她上一条多久、这个时段她平时来不来（统计） |

## 二、候选与激活度

**候选**：
- 回忆：经历投影的可见行（情节优先），与"话"有字面重合的（FTS trigram；两个字的词 trigram 切不出，用 LIKE 补；取重合最多的前 K 条）；本会话这一轮之内的不算（同 recall 的回声规则）。
- 预期：现行书架条目，`when` / `watch` / `quote` 与"话"重合，或条目关于这一轮说话的人。
- 预感：她到这个时段的到达占比 ≥ P（统计，最近 28 天），而此刻距她上一条 ≥ 平时间隔的 N 倍；她平时这个点几乎不来 → 不报（静默闸门）。

**激活度** = 基础强度 + 线索匹配 + 噪声：
- 基础强度：被想起的次数与近因（`surfaced` / `recalled` / `detail` 过）、写了 `felt`、有后果（被书架条目挂成证据、被改写）；书架条目另加证据数与最近一次证据的近因。
- 线索匹配：字面重合度（trigram 命中数 / 长度），同一个人、同一地方、同一时段各加一点。
- 噪声：随机扰动，种子可固定（考卷可复现）。

各项权重先给缺省值，写在一处，用考卷调。

## 三、处境调制

| 处境（读得出来的事实） | 阈值 | 每轮最多 | 噪声 |
|---|---|---|---|
| 手上有任务：本会话最近 10 分钟工具调用 ≥ 3 次 | 高 | 1 | 低 |
| 在聊：她在说话、没有密集工具调用 | 中 | 2 | 中 |
| 刚醒 / 隔了很久回来（距上一轮 ≥ 2 小时） | 低 | 3 | 高 |

## 四、刹车

- **不应期**：同一条浮现过后 72 小时内不再浮（按条目；书架条目按现行版的条目算）。
- 浮现记 `surfaced` 事件：`{ ref: <事件 id>, source: "recall|expect|hunch", score, cue }`。`cue` 记在事件里供评测，**不渲染给它看**（render 已返回 null）。
- 浮现算"被想起一次"，进基础强度；一个不应期窗口内只算一次（闭环封顶）。

## 五、REST 与注入

- `GET /v1/now?session=` 多一块（有才出）：
  ```
  想起：
  [10-06#12] 10-06 21:54 <它写的那条情节正文>
  [10-14#6]（明说的规矩）<它写的条目>；原话：「…」
  阿禾：平时这个时段来的占 60%；上一条在 2 天前
  ```
  回忆和预期是它自己写的文字（或原话），预感只陈述事实，不写"她可能生气了"。
- 每次 `GET /v1/now` 都算一次浮现、写 `surfaced`。Soma 每轮取一次 `<now>`，不用改。
- `GET /v1/surface?session=&dry=1`：只算不写，考卷和调试用，返回各候选的分项得分。

## 五½、向量（10-14 Joy 定）

- 混合：字面（汉字两字组按 IDF 加权）管准，向量（bge-m3）管意思相近。recall 也改成混合（字面 + 向量按名次合并，RRF）。
- 向量不是投影（要调外部服务）：`p_vec(ref, model, vec)` 是投影旁的派生缓存，后台补齐，换模型整套重算；没配嵌入服务就只用字面。
- **测试先用硅基流动**（`PSYCHE_EMBED_URL` / `_MODEL` / `_KEY`）。算向量发出去的是原文：正式库出生前另定（换本地或确认接受）。
- bge-m3 的余弦：相关的约 0.65+，不相关的短句也有 0.4–0.5 → 只用向量分不开短线索，字面那一份不能少。

## 五¾、实现时定下的细节（考卷 A 撞出来的）

- 线索分两份：她这一轮的话（字面、留意词只看它）和前几行（只在她的话太短时一起嵌入）。前几行混进字面，旧话里的"嗯"会一直撞书架的留意词。
- 正文不足 5 个字的行（"嗯""好"）不当回忆：没内容，只会被短线索撞上。
- 刚醒 / 隔很久回来：**上次怎么散的**（另一个会话里和她的最后几行）作为一条固定想起，不和别的比分；预感同样固定出现，不占比分名额。
- 阈值：有任务 0.9 / 在聊 0.6 / 刚回来 0.5；权重都在 `surface.ts` 的 `W`。
