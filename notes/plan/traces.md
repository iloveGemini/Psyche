# 契约：时间感——回想出口只给大概（traces）

> 设计见 `notes/design/traces.md`（10-24 Joy 定）。本文件只管接口与格式；改格式先改这里。
> 事件里的 `at` 不动；REST 返回的 `at`（毫秒）不动（dashboard、档案馆照旧精确）。模糊只在**递到它眼前的文字**那一步。

## 一、两个确定的函数（`src/core/time.ts`）

### `vagueWhen(at, now, timeZone) → string`

| 离此刻（按自然日） | 返回 | 例 |
|---|---|---|
| 同一天 | `今天<时段>` | 今天上午 |
| 前 1 天 | `昨天<时段>` | 昨天深夜 |
| 前 2 天 | `前天<时段>` | 前天下午 |
| 前 3–6 天 | `MM-DD（周X）<时段>` | 10-21（周三）晚上 |
| 更早 | `MM-DD` | 10-13 |
| 不在今年 | `YYYY-MM-DD` | 2025-12-31 |
| 比此刻晚（时钟不齐） | 按同一天处理 | 今天下午 |

时段按自然日零点切，不跨零点回拨（与档号日期对齐）：凌晨 `[0,5)`、早上 `[5,8)`、上午 `[8,11)`、中午 `[11,13)`、下午 `[13,17)`、傍晚 `[17,19)`、晚上 `[19,23)`、深夜 `[23,24)`。

### `gapHint(ms) → string | null`

| 相邻两条的间隔 | 返回 |
|---|---|
| `< 10 分钟` | `null`（不插） |
| `[10, 30) 分钟` | `（过了一会儿）` |
| `[30, 60) 分钟` | `（过了半个多小时）` |
| `[1, 24) 小时` | `（隔了约 N 小时）`，N 四舍五入，最少 1 |
| `≥ 24 小时` | `（隔了约 N 天）`，N 四舍五入，最少 1 |

## 二、两种行格式

**单行**（不按时间顺序的列表：recall、冷写的 feedback / observations / candidates、浮现）：

```
[10-24#12] 今天上午 Joy 说：……
```

**时间流**（按时间顺序的一整段：热写全文、冷写 `<material>` 每个会话组、Soma 种子末尾原话）：时段变了起一行标题，相邻间隔按 `gapHint` 插一行；行首不再带时刻。

```
── 今天凌晨 ──
[10-24#3] Joy 说：……
[10-24#4] 我说：……
（过了一会儿）
[10-24#5] Joy 说：……
（隔了约 3 小时）
── 今天早上 ──
[10-24#9] （醒来 · 补写）
```

**留意过的给精确**：`kind` 是 `notice`，或是 `percept.noticed` 且 `looked`（它自己 look 的）——两种格式里都在正文前加 `〔MM-DD HH:mm〕`（它当时看了表）。

## 三、出口清单

| 出口 | 格式 |
|---|---|
| MCP `hotwrite_segment` 眼前会话（`brief`） | `[档号] 开头`，不给时刻 |
| MCP `hotwrite_segment` 全文（`full` / 带 `session` 补写） | 时间流 |
| MCP `recall` | 单行 |
| MCP `coldwrite` 材料 | `<material>` 每个会话组一段时间流；其余单行 |
| MCP `detail` | 原件 JSON 前加一行 `原件时刻：YYYY-MM-DD HH:mm:ss（周X）`（付成本去查，给精确） |
| `<now>` 浮现（`surface.ts`） | 想起的那几行用单行；节律提示「上一条在 N 小时前」去掉括号里的 `MM-DD HH:mm` |
| Soma 种子末尾原话（`transcript.ts` `tailOf`） | 时间流（标题用 `vagueWhen`，没有档号）；Soma 自己实现同一套规则 |

**不变**（不是回想）：`<now>` 的此刻与这一刻递到的感知；作息、闹钟、下次醒；线索卷碎片；自述改版时刻；信箱列表（收件箱上的时间戳，相当于翻记录）；dashboard 与全部 REST JSON。
