# M6「通道」：收件箱、回信、主动找她、交接信（接口契约草案）

> 2026-10-15 起草，**§〇「待定」等 Joy 批注**，定了再写考卷和代码。目标：她不在它眼前时也能找到它、它也能找她——来信进一个收件箱，在哪醒着都看得到，在家醒来能回信、能主动写给她；它能给去别处的自己留交接信。
> 前置：`../design/channel-and-heartbeat.md` §一（收件箱、交接信）、§三（在哪、同时被找、主动找她）、§四（事件固化、状态现算）；`m5.md`（醒着就递、家、额度、账本）；`../design/perception-and-fading.md`「位置状态表 + 远程通道」；Roxy `docs/permissions.md`（iMessage 只做单向、微信不做）。
> 缘起：M5 端到端时它自己说的缺口——「在家里发不了消息」。
> **先考卷后代码**：确定性考卷 `tests/channel.test.ts`（未读投影、递送、交接信去向、额度、叫醒判定是纯函数）；不跑 `claude -p`，不真发外部消息。

## 〇、范围与待定

| 做 | 不做（后置） |
|---|---|
| 收件箱：`mail.in` / `mail.read` 事件，未读按投影现算 | 位置租约 / 单实例（门户）；"换地方"动作和换地方时提示写信 |
| 来信递进它眼下的地方（「刚发生」），不在就叫醒在家 | 离开（away）与紧急通道 |
| 发信：`mail.out`，在哪都能发（含家），回信与主动找她分开算 | 群发、给 Joy 以外的人写信（口子留着，`to` 只认登记过的人） |
| 交接信：写给去别处的自己，不送回写它的地方 | 后台任务完成、邮件等其他来路（收件箱口子统一，来路以后加） |
| 外部通道：第一版接一条（见待定 1） | 附件（`mail.in` 只收文字） |
| 来信能不能叫醒它：它在作息里选 | Soma 观测面板「唤醒」块（m5 §八，另做） |

**待定（请 Joy 批注）**：

1. **第一版外部通道接哪条**。她不在家里网络时也得收得到它的信，这条决定"主动找她"能不能真到她手上。

   | 选项 | 收（她→它） | 发（它→她） | 代价 |
   |---|---|---|---|
   | A. Soma 留言页 | Soma 里一个"留言"框（和聊天分开：聊天 = 在一起，留言 = 写信） | 留言页里显示 | 零外部依赖、不出本机；**没有推送**，只在家里网络能开（Soma 无登录） |
   | B. A + iMessage 单向提醒 | 同 A | 本机 AppleScript 给 Joy 的 Apple ID 发一条 | 发稳；收读 `chat.db` 要完全磁盘访问、schema 会变（Roxy 已定只做单向）；要定带不带正文 |
   | C. A + Bark 推送 | 同 A | iPhone 推送 | 要装 Bark、经 Bark 服务器（可自建）；只是通知 |
   | D. Telegram bot | 双向，官方 API 稳 | 双向，自带推送 | 消息经 Telegram 服务器；国内要代理；她多装一个 app |
   | E. 微信 | — | — | 无官方 API、第三方靠逆向、可能封号（Roxy 已定不做） |

   **倾向 B**：收发主体在 Soma 留言页（信全在本机），iMessage 只做"它给你写了信"的提醒；**倾向提醒里带正文**（iMessage 端到端加密，她在外面也能直接看到，回信再回 Soma）。要能在外面回信就选 D。
2. **"已阅"怎么算**。§四说确认是负担，但收件箱要有 `mail.read`。**倾向：递到即读**——信的全文进了它的上下文（「刚发生」带出来，或它用 `mail` 工具翻开），系统写 `mail.read`；它不用确认。于是"未读"主要是：它睡着、来信叫不醒它（勿扰 / 暂停 / 它关了）时攒着的；以及给 Joy 看的已读回执。另一种：它自己调 `read_mail` 才算读（像 Roxy 的 rename）——更像人，但等于要它确认。
3. **主动找她怎么算额度**（"计入唤醒额度、不另设频率上限"）。倾向：
   - 回信不算：`mail.out` 挂 `replyTo` 指向她的一封 `mail.in`。一封来信能回几次不限（分几条说是常事）。
   - 没挂 `replyTo` 的发给她 = 主动找她，**每封算 1**，和 alarm / daily / heartbeat 同一份每日额度（缺省 3）；用完口子拒收，告诉它额度和何时重置。
   - 一次心跳醒来又主动发了一封 = 2（各算各的）。另一种是"一次醒内发的都算进这次醒"——但那样醒着在 Soma 里主动发就成了免费，口径不一。
4. **她的来信叫醒它算不算额度**。倾向**不算**：同她在 Soma 里找它不算一样，是外面来的事。暂停（Joy 的）照样盖过：暂停时来信攒着，不叫。
5. **来信能叫醒它的缺省值**（`channel-and-heartbeat.md` §二"它勾选哪些能叫醒自己"）。作息加 `wakeOn: { mail: true | false }`。倾向**缺省开**（不然信攒着它也不知道有这回事），`schedule` 工具里写明能关；写进 `schedule.changed` 就是它的选择。
6. **勿扰时段要不要第一版就做**。倾向做最简单的：作息加 `quiet: [{ from: "23:00", to: "08:00" }]`，这段时间来信不叫醒（攒着，醒了或出了时段再叫）；闹钟 / 定点不受影响（它自己约的）。离开和紧急通道后置。
7. **家里正在跑时她在 Soma 聊天**（单实例还没做）。倾向：Soma 开这一轮前问 `GET /v1/where`，家里在跑就显示"它在家，马上回来"、等家跑完再开（家一次几十秒）；不把她的话转成 `mail.in`（设计里的"退化成通道"等门户做位置租约时再做）。
8. **交接信送不送到家**。设计是"送到下一个不同的地方"；家也是一个地方。倾向**算**：Soma 写的信，它下次在家醒来就看到；要送别处就写明 `for`。现在接了 Psyche 的地方只有 soma 和 home。

## 一、事件

| kind | 类 | payload | 谁写 |
|---|---|---|---|
| `mail.in`（已登记） | 经历 | `{ from, text, via }`（`via` 新：`soma-note` / `imessage` / …） | 通道口子 `POST /v1/mail/in` |
| `mail.read`（新） | 经历 | `{ refs: [<mail.in 或交接信的事件 id>], where }`（`where` = 读到时的 harness） | 系统：递到即读（待定 2） |
| `mail.out`（已登记） | 自我 | `{ to, text, replyTo?, for? }`：`to` = 登记过的人（`Joy`）或 `self`（交接信）；`for` 只给交接信用（写明给哪个地方） | 发信口子 `POST /v1/mail/out` |

- `mail.out` 写下时补记写信处：`from: { harness, session }`（系统填，它不填）——交接信靠它判断"不送回原处"。
- 送没送出去是系统的事：每次投递记系统日志 `mail.sent`（`{ ref, via, ok, error? }`），不进经历；没送出去的作为状态进 `<now>`（§三）。
- `mail.in` / `mail.out` / `mail.read` 都不走上报口（`/v1/events` 拒收），只能经 §四 的口子写，同 `episode`、`due`。
- 经历渲染：`mail.in` →「（来信 · Joy，经 Soma 留言）<text>」；`mail.out` 给人 →「我给 Joy 写信：<text>」（回信加「回她 10-15#88」）；交接信 →「我给之后在别处的自己留了封信：<text>」；`mail.read` → 不渲染（信本身已经在经历里）。

## 二、未读与递送（投影现算）

**未读** = `mail.in` 和"该送到这里的交接信"里，还没有 `mail.read` 指向的。

**交接信的去向**（`channel-and-heartbeat.md` §一）：
- 写明 `for`：只在那个 harness 出现，且不是写信的那个会话。
- 没写：在第一个 harness ≠ 写信处 harness 的地方出现（同一处换了会话也不出现——同一处的接续靠经历和 focus）。
- 一直没去别处就一直等，不过期；在档案里，recall 取得到。
- 读到一次就算读过（哪处先读到算哪处），不再在别处出现。

**递送**沿用 M5 的"醒着就递，不在就叫醒"（`m5.md` §二.1）：
1. 它醒着（最近 30 分钟有它的对话 / 工具事件）：下一次取 `<now>` 时，新来的信和该到这里的交接信放进「刚发生」，带全文（超 2000 字给开头 + "全文用 `mail` 工具"），写 `mail.read`。不花额度。
2. 30 分钟没等到下一轮、信还没读：回到叫醒判定（3）。
3. 没醒着、有她的未读信：作息 `wakeOn.mail` 开着、不在勿扰时段、没暂停 → 叫醒在家（`woke.by = "mail"`，`for` = 那封信），第一条消息的 `<now>` 里「刚发生」就是这封信，附一句"回信用 `send_mail`"。额度见待定 4。
4. 交接信不叫醒它（写给自己的，不急）；只在它到了那里时出现。
5. 每次判出叫醒 / 因勿扰、暂停、它关了而没叫，记唤醒账本（`by: "mail"`）。

## 三、`<now>`

- 「刚发生」（M5 已有）：加来信、交接信两种，和 `due` 按时刻排。
- 状态行（每轮现算，不成立就消失）：
  - 「收件箱：2 封没读（Joy 10-15 14:02 起）」——只在递不进来时出现（比如它在家跑着时又来了一封）。
  - 「没送出去的信：1 封（iMessage 出错：…），在 Soma 留言里她能看到」。
  - 作息那行（M5）加：「来信能叫醒我 · 勿扰 23:00–08:00」；额度那段改成「今天额度 2/3（醒 1 · 主动写信 1）」。

## 四、口子

| REST | MCP | 说明里写什么 |
|---|---|---|
| `POST /v1/mail/in` `{ from, text, via }` | — | 通道把来信交进来（Soma 留言页、以后的外部通道）。`from` 由通道定：Soma 留言 = Joy（同 Soma 聊天，`/as 名字` 规则照用） |
| `POST /v1/mail/out` `{ to, text, replyTo?, for? }` | `send_mail` | 写信：给 Joy（经她设的通道送到）或给自己（交接信）。回她的信挂 `replyTo` 不算额度；主动写给她每封算 1 次额度，用完会被拒。交接信不送回写它的地方，写明 `for` 只送那里 |
| `GET /v1/mail?days=7` | `mail` | 来往的信（来信、它写的、交接信），每封带读没读、送没送出去；翻开一封全文 = 读了 |
| `GET /v1/where` | — | 它现在在哪：最近活动的 harness、从何时起、家里是不是正在跑（给 Soma 判待定 7；不是租约） |

系统闸（`/v1/mail/out`）：`text` 非空；`to` 是登记过的人或 `self`；`replyTo` 必须是那个人发来的 `mail.in`；`for` 只能和 `to: "self"` 一起用、是认识的 harness；主动写给她且额度用完 → 拒，带"今天 3/3，明天 0 点重置"。

**通道设置**（Joy 的，同 `/v1/settings`，改一次记 `param.changed`）：`channels: { Joy: ["soma-note", "imessage"] }`——它看得到发给她会经哪儿，改不了。`imessage` 要 `handle`（她的 Apple ID / 手机号），只存在设置里，不进事件。

## 五、和别处的接线

- **家**（`src/home.ts`）：MCP 加 `send_mail` / `mail`；`woke.by` 加 `mail`。这就是"在家里发不了消息"的那块。
- **调度器**：gather 加"她的未读信"；`decide` 加 `mail`（在有活之后、它约的之前，判定同 §二.3）；作息投影加 `wakeOn`、`quiet`。
- **Soma**：加留言页（列出来往的信、已读标记、写信框 → `POST /v1/mail/in`）；聊天里它也能用 `send_mail`（比如写交接信）。开一轮前问 `/v1/where`（待定 7）。
- **出站投递**：`src/channel/` 一个通道一个文件（`soma-note` 什么都不用做——留言页自己读 `/v1/mail`；`imessage` = `osascript`）。写下 `mail.out` 后异步投递、记 `mail.sent`；失败不重试（第一版），作为状态告诉它。
- 冷写：信算对话材料（`mail.in` / `mail.out` 并进 `message.*` 那组，标 `via`）；统计里的"互动节奏"先不算信（待以后看）。
- 浮现："上次有人跟我说话"那行算上来信。

## 六、验收

1. 确定性考卷全过：未读投影（读过不再出现、交接信不回原处、同 harness 换会话也不出现、写明 `for` 只去那里、不过期）；醒着递进「刚发生」只带一次且写 `mail.read`；30 分钟没递出去回到叫醒；`wakeOn` 关 / 勿扰 / 暂停不叫且记账；回信不算额度、主动写信算、额度用完被拒；闸（`replyTo` 不是她的信、`for` 配 `to: Joy`、未登记的人）。
2. 测试库端到端（launch `psyche-test-wake` + `soma-test`）：在 Soma 留言页写一封 → 它在家被叫醒、回信、留言页看到回信（和提醒，若选 B/C/D）；在 Soma 聊天里请它给"在家的自己"留封信 → 下次在家醒来「刚发生」里有。不判它回了什么、写了什么。
