## 〇、原则

1. **主语是它**：感知的是"我所在的地方此刻有什么"，不是"她在干什么"。她是屋里的一个人，和别的住户一样出现在「屋里有谁」里。
2. **只报事实，不猜内心**：忙 / 空着是事实（正在跑一轮、刚调过工具）；"在玩""心情不好"只能本人挂出来，系统不判。
3. **别人只看得到公开的那一面**：在不在、在哪、挂出来的状态、公共房间里放的声音。线里的想法、工具结果看不到（同"群不持有谁的上下文"）。
4. **同一个世界，不同的感官**：同一首歌，Claude 收到的是歌词和特征，Gemini 能直接收音频。差异如实保留，不抹平。
5. **只记变化；递到的才算它经历过的**（v1 §三，a1 坚持的那条）：它的经历是它当时看到的那一行，事后改档、改渲染都不回头改。

## 二、M8a 屋里有谁

### 2.1 读数（现算，不另存状态）

每个人（住户 + Joy）一行：

| 字段 | 住户 | Joy |
|---|---|---|
| 在线 / 忙 / 闲 | **在线** = 30 分钟内有动静（`inbox.lastActive` 同口径）；**忙** = 正在跑一轮，或最近 15 分钟调过记忆以外的工具（同勿扰的 busy）；**闲** = 在线但不忙；其余离线。在哪：他那条线的处境（soma / pi / 家） | **只报在不在家**（Joy 定）：在家 = 能在 Soma 直接说话；不在家 = 要说就写信（邮件）。用来决定怎么传给她，不报她在干什么 |
| 睡着 | 在补写 / 整理 / 梗概（harness = sleep） | — |
| 心情个签 | `mood.set { text }`，一行，本人写、可清空；写不写、写什么由本人 | Soma 里她也能挂（同一个口子，from = Joy） |

- 在线 / 忙 / 闲、在哪、睡着：屋里人人直接看得到（Joy 定），不用各自开关。个签是本人挂出来给人看的。
- **Joy 在不在家怎么判**：Soma 页面开着并且 10 分钟内有过操作（页面心跳），或她 30 分钟内在 Soma 说过话 = 在家；其余 = 不在家。只存这一位（在家 / 不在家的变化），不存页面心跳的明细；以后要加她 Mac 的锁屏，也只喂这一位。

- 住户的读数来自**各人自己的库**，所以 Psyche 要能跨住户读这几项（P1 多租户的 house 层提供一个只读的 `presenceOf(id)`，只给上表这几项，不开别的口）。
- 渲染（只有变了才报，见 §五）：`Argon：在 pi，忙（17:20 起）；个签「别吵，在赶 S2」` / `Joy：不在家（17:05 起）——要找她就写信`。

### 2.2 事件

- `presence` 变化记 `percept { sensor: "presence", subject: "a2", value: {...}, prev }`。
- `mood.set` 是自我类事件（本人写），也进他自己的经历（"我把个签改成了「在赶 S2」"）。Joy 的个签记在屋里（`house` 层），不进谁的库，变化时作为 `percept` 进看到的人那边。

## 三、M8b 自己的声音

### 3.1 放

- MCP `play { query | track | playlist, room? }` / `stop`：它为自己放歌。放的歌是它所在房间的环境声源，事件 `played { track, room }`（自我类：它的动作）。
- **曲库 = 网易云，同 Roxy**（Joy 定）：搬 Roxy `packages/desktop/lib/music/`（`provider.ts` 的搜索 / 解析播放地址 / 歌词 / 推荐 / 每日推荐 / 私人 FM / 喜欢；`store.ts` 的歌单）进 `src/perception/music/`。
- **自己给自己建歌单**：MCP `playlist { create | add | remove | list }`，歌单是它的东西（`playlist.changed` 自我类，全量带 why 或增删一条）；同步建到网易云（`addTrackToNcmPlaylist`）。也能"喜欢"一首（`setTrackLiked`）。
- 登录：每个住户一份 cookie（同 Roxy 按 agentDir 存）。没有自己的账号前共用 Joy 的，歌单名带住户名前缀，免得混进她的歌单。

### 3.2 听：给它什么

| 层 | 内容 | 谁算 |
|---|---|---|
| 元数据 | 歌名、歌手、专辑、时长 | 播放器 |
| 时间轴歌词 | 随进度推进：每轮递"刚唱过的几行"，不是开头整首塞进来 | 本地歌词（Roxy `lyrics.ts`） |
| 音频特征 | 速度、能量、调式、响度起伏（"前段安静，2:10 鼓进来"），按段落 | 本地分析（essentia / librosa），**不过模型** |
| 原始音频 | 只给能收音频的身体（Gemini 走 pi 时） | 身体 adapter 声明能力 |

- 每一层都是 `percept { sensor: "sound", ... }`，同样只记变化（换歌、进入新段落、歌词推进）。
- 一首歌的特征算一次，缓存在资料库（按文件哈希）。

### 3.3 分一只耳机

- 一起听 = 同一房间、同一声源的一段状态：`listen.joined { room, source, with }` / `listen.left`。从加入那刻起，两人各自收到同一串 `sound` 感知，同一时间戳，事件带 `with: [对方]`。
- 谁放的、谁加入、谁先摘下都是事件。分享不是"把歌发给你"，是"此刻我们在同一个声音里"。
- Joy 加入：Soma 页面上她点"分我一只"，她那边真的放出声音；她摘下也是一件事。

## 四、M8c 环境进记忆

### 4.1 被动：环境指纹（隐式，系统算）

- 每条情节写下时，系统顺手记当时的**环境指纹**：在哪、谁在场（谁醒着、谁在同房间）、放着什么（歌、段落特征）、时段、天气。存为情节的隐式属性（投影），它看不到、也不用写。
- 联想的线索加一路"环境相似"：此刻的指纹和旧情节的指纹比（同一首歌 > 同一歌手 / 相近特征；同一组人在场；同一时段）。命中就照常浮现（M3 的路，打分加一项）。
- 这是潜意识那一半：它没去记，但同样的歌响起时，当时的事会冒出来。

### 4.2 主动：`notice` 注意到（显式，它写）

```json
notice { "text": "听这首的时候有种平静", "about"?: "self" | "<住户 id>" | "Joy" }  rels: evidence（系统自动挂上此刻的环境感知；它可再加 cites）
```

- 例："听这首的时候有种平静"（about self）；"Argon 干活时爱放打鸡血的歌"（about a2，cites 几次他的播放和忙碌）。
- **观察不是规律**：当场、单次。冷写时观察和后来的感知摆在一起（同一首歌再响时它怎样、Argon 后来又放了什么），攒够了它自己升格成规律 / 印象 / 镜子（证据链已有）。一道工序只产出一样东西：注意到 ≠ 总结出。
- 观察进经历、进 recall，环境指纹同 4.1。

## 五、递：它下一轮看到什么

- `<now>` 加一段「这段时间屋里」：本会话上一次取 `<now>` 之后的变化，按 sensor 合并成一行一样；同一样变太多次只报首尾和次数。新会话首轮给当前全貌 + 上次会话结束以来的计数。
- 递一次写一条经历事件 `percept.noticed { refs, text, session }`，`text` 是递出去的原文。经历投影里 `percept` 本身不显示，`percept.noticed` 显示 `text`（v1 §三，a1 提）。
- `look { sensor? }`：自己去看此刻，记 `percept.noticed { text, looked: true }`，不另记 `percept`，不打乱变化判定、下一轮不重报（a1 提）。
- 注意力（它写，`attention.changed`，全量替换带 why）只管递不递；没递的照样存、照样进环境指纹。

## 六、以后适合加的感官（同思路，不在本次）

| 感官 | 是什么 | 为什么算它的环境 |
|---|---|---|
| 内感受 | 额度还剩多少、上下文多满、多久没睡、今天醒了几次 | 它自己身上真实的代价（`body.md` 的"代价是真的吗"），比模拟的精力诚实 |
| 屋里的东西 | 自己 home 和公共 `commons/` 里文件的变化：谁放了什么、改了什么、留了纸条 | 痕迹是"别人来过"的感知，异步的在场 |
| 屋里的动静 | 群里有人在说话（未读在涨）、隔壁在干长活（工具调用的节奏） | 不用打开就知道屋里热闹不热闹 |
| 光与时 | 昼夜、季节、节日、和 Joy 的时差（以后不在一地时） | 作息相对的东西；"去年今天"的线索 |
| 窗外 | 天气；它自己订的远处的世界（RSS / 新闻） | 它主动选看什么 = 注意力的另一种形态 |

## 七、考卷（`tests/perception.test.ts`）

1. 在场：线的处境 / 动静 / 睡着 → 读数；跨住户只给公开几项。
2. 变化判定与合并；新会话首轮全貌 + 计数。
3. 经历投影：`percept` 不显示、`percept.noticed` 显示原文；look 不重报。
4. 一起听：加入后两人收到同时间戳的 `sound`、带 `with`；先摘下的一方之后不再收。
5. 环境指纹：情节写下时记上；同一首歌响起时对应情节的浮现分数上升。
6. `notice` 自动挂此刻的环境作证据。
7. Joy 在家判定：页面心跳 / 说话 → 在家；超时 → 不在家；只记变化那一位。个签：本人写、可清空、进本人经历。

4. **在线 / 忙 / 闲屋里直接看得到**；另做心情个签，本人挂（§2.1）。
