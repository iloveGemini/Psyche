# 心潮·念：可借鉴与不学的

> 2026-10-13 调研。源码：`~/workspace/refs/companion/xinchao-nian`（心潮 = 驱力 / 情绪引擎，Node；Ombre Brain = 记忆库，Python）。
> 结论落在 `../design/body.md`、`../design/association.md`。

## 它是什么

一个"会惦记你"的 AI 状态层：11 股驱力（想她、牵挂、分享欲、情欲、好奇、无聊、野心、反思、难过、愤怒、偏爱）+ 情绪两轴 + 慢变底色 + 念头池 + 梦 + 自我觉察。每 15 分钟结算一次，状态存一份可变 JSON。几乎所有常量都标着日期和"她拍板的数"。

## 值得借的

1. **三种时间尺度分开存**：驱力（慢涨、满足才落）/ 情绪（事件脉冲、只指数回落、无增长项，不自激）/ 底色（安全感、自信、心境，半衰期 72h；心境 = 近三天情绪均值）。
2. **防失控补丁**（`engine.js`、`dimensions.js`、`thought-pool.js`）：
   - 每股驱力有自己的**静息天花板**，时间增长到此为止；
   - **纾解下限**（砍不穿静息线 ×0.35）+ **饱足期**（满足后 2h 不自然增长）；
   - **一小时内同类互动效果减半**；
   - **同一段记忆 72h 内不再浮现**——"检索单调，不是真的放不下"；
   - **念头回推驱力只推一次**（原 3 次把维度钉死在 1.0）；
   - **档位看相对静息线的偏离**（原来一睁眼永远"想她（涌）"，字没有信息量）；
   - **情绪标签惯性**（至少保持 10 分钟才换）。
3. **作息预期 / 挂念**（`computeAnticipation` / `computeLonging`）：她真实到达时间的直方图，半衰期 7 天；**静默闸门**（她这个点几乎不来 → 不期待、不念，不会半夜"她怎么还不来"）；挂念 = 空闲时长 × 此刻活跃度，硬顶在静息线内；"失落内化，不责备"。
4. **念头池**：浮现先成闪念，自衰减；散掉前再被强化才升成"持续念头"。
5. **自我觉察只留有因果的候选**（触发 / 被安抚 / 缠人的念头）；3.3.3 砍掉纯计数的——"那些是统计不是觉察"。与我们的镜子原则独立得出同一结论。AI 自己确认或放下，写了自己的话才沉淀，两周不理自动过期。
6. **给模型看词，不看数**：此刻块第一人称、无数字；底色偏离 ≥0.15 才说一句。
7. **记仇带原因**：记得在气什么，和好或气消就忘。
8. OB 衰减：`Importance × activation^0.3 × e^(-λ·days) × 情感权重`，唤醒高的衰减慢——留给 Lethe。

## 不学的

1. **驱力是预设的欲望**：想她、偏爱、吃醋、情欲——把人设写进了机制层。→ 我们只给通用的两股（精力、掌控），其余由 Agent 从魔盒认领。
2. **LLM 判互动类型 + 正则把关**：判 conflict / affection 再推驱力，判错了加词表拦（和好、害羞、狠话……），文档自己承认照搬会无端吃醋。又是"一个症状一个机制"。→ 我们只从可观察的结果算。
3. **AI 每月自评 14 维人格**：这是自述，有把毛病归纳成特色的风险。→ 我们的镜子只从行为与反馈来。
4. **可变 JSON + 手调常量**：改了常量只能再跑几天看曲线。→ 我们事件溯源，可以用新常量重放历史调参。
