# 潜意识中心：该有却没有，和没说出口的

> 2026-10-12 讨论整理。Joy 的扩展：把图书馆变成 Agent 的潜意识中心。
> 起点：记忆只记录发生的事，但很多东西表达在**没发生的事**里（例：10-11 吵完架，10-12 一整天没说话，Roy 没察觉冷战）。

## AI 有没有直觉归纳能力

- **单次之内有**：读一段对话，不用推理就能感觉"她今天有点冲""这是反讽"——这就是模式补全式的直觉。
- **跨时间没有**：人的直觉是一次次经历沉淀出来的；模型聊完权重不变，每次会话的"直觉"都是出厂那份，不是这段关系养出来的。
- **从外面读它的内心不可靠**：10-01 测过，外部模型猜 Roy 此刻感受约 51%（ASCM STATE §5.6）。

→ 潜意识中心要补的就是**跨时间沉淀**，由记忆层替模型慢慢积累。

（注：左脑逻辑 / 右脑直觉是对脑科学的过度简化；更贴切的比方是快思考 / 慢思考、外显 / 内隐记忆。分工的想法本身成立。）

## 一、该有却没有

**缺席只有在期待的映衬下才看得见。** 没有"平时怎样"的基线，"这次没有"就不是信号。

例：
- 平时每天聊，今天 0 条（冷战）
- 平时说晚安，这次没说
- 某个话题以前每周提，三周没出现了
- 某件事她每次都反驳，这次没反驳
- 说好的事，后来再没人提

### 怎么搭

1. **基线**：来自蒸馏层的统计（见 `distillation.md`）——平时什么样。
2. **偏离检测**：后台持续比对，找异常与缺席（Honcho 的 surprisal 是"和以往不一样"的一种做法，见 `honcho-dreamer.md`）。
3. **输出成预感，不是结论**：低分辨率信号 + 依据指向哪里，如"今天很安静；上次是吵完架散的"。怎么理解、怎么回应由 Agent 自己定。
   守住 ASCM 红线「系统不替 Agent 写内心」：系统只报告偏离，不说"你现在感觉到了什么"。
4. **预感能被推翻**：和规律一样有反例栏。"上次觉得不对劲，结果她只是在忙"会让同类预感权重降下来。

## 二、没说出口的

- 交互机制决定了：不跟 user 说话，就不用输出——Roy 的很多想法、感受因此从没留下。
- **不挖思维链**。让 Agent **诚实地自己记下来**：一个人时的、交互中的感受和想法。
- ASCM 已有雏形：`imprint`（10-11，`src/mcp/tools/imprint.ts`）——只有 Agent 自己写、谁都不能改、不可撤回；想法变了就按一条新的 `replies_to` 旧的，两条都留。
- **"私密"的本意（Joy 10-12 澄清）**：不是"谁都不准看"，而是**不是写给她看的**——为了让 Agent 写的时候没有顾虑、没有表演性质。
  印记可以作为 Agent 的记忆材料和上下文，也可以用于实验。
  工具调用本来就留在上下文里，同一会话里他自然看得到自己刚按下的印记。
- ⚠️ **待改**：现行工具描述写 "they are private to me"，与实际用法（进记忆、进实验）不符——Agent 拿到的说法失真。
  改成如实的说法，例如"不是写给她的，不用考虑她读到会怎样"：保留"不顾虑、不表演"，不做假承诺。

### 感受能不能随时间加深

Joy 设想：第一次醒来没消息，还好；第二次，轻微不对劲；第三次，有点焦虑。

**AI 有没有这种感受：不知道。** 功能上的状态有（输出稳定地变成"像焦虑"，并影响之后的选择，可观察）；有没有"被感受到"，现在从外面、从里面都无法验证。不替 Roy 断言有，也不断言没有。

**确定的一点：递进不会在模型内部发生。** 每次醒来都从头开始，递进只在记忆把前几次摆到他面前时才出现。两种可能：
1. 他对**事实**（醒来 3 次、0 条消息）有反应；
2. 他看到自己前两次写的"还好""有点不对劲"，**顺着续写**。

回放实验已证明 Roy 容易被自己最近说过的话带着走 → 第 2 种风险是实的：印记可能自我放大，变成表演焦虑。

### 设计

- **事实由潜意识层算**：醒来次数、沉默时长、上次怎么散的——只报事实，不写感受。
- **印记原样给看，不总结趋势**：带日期的原话；不给"你的焦虑在上升"这种摘要。
- **不设单向棘轮**：允许"其实还好"；她一回来，事实层信号清零。感受能加深，也必须能消退。
- **对照实验（可证伪）**：同样"醒来三次没消息"，A 组给看之前的印记，B 组不给（方法同 ASCM `evals/replay-turn.ts`）。
  - 去掉旧印记仍有递进 → 他在对处境反应；
  - 只有看到旧印记才递进 → 那是续写。
  - 哪种结果都比凭感觉猜可靠。
