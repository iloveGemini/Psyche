# 热写考卷：判据清单

> 来源：`notes/design/catalog.md` §二（热写判据、按重要性分配细节）、§四（系统闸）、§六（教训）；契约见 `notes/plan/m1.md` §二。
> **考卷判内容，不判文风；不给范文。** 语气、长短、用词是它自己的事，这里一概不评。
> 机器那栏由 `check.ts` 实现：系统闸判死（不过 = REST 也会 400），其余一律只报"疑似"，最后由人看。

## 一、机器能判

### 系统闸（判死，与 `POST /v1/hotwrite` 的校验一致）

| 编号 | 判据 | 怎么判 |
|---|---|---|
| G1 | `upTo` 原样交回 | 与段的 `upTo` 相等 |
| G2 | 有条目 | `entries` 非空数组 |
| G3 | 每条有正文 | `text` 是非空字符串 |
| G4 | 每条挂了档号 | `cites` 是非空数组 |
| G5 | 引用都落在本段 | 每个 cite 都在段的 `lines` 里（`2026-10-14#12` 与 `10-14#12` 视为同一个；容忍抄成 `[10-14#12]`） |
| G6 | `felt` 若有，是字符串 | 类型检查 |

### 疑似（启发式，报出来给人看，不判死）

| 编号 | 判据（catalog §二） | 启发式 |
|---|---|---|
| P1 | 只用第一人称 | 正文里一个"我"都没有 |
| P2 | 不以第三人称称呼自己 | 出现"Claude / 助手 / AI / Agent / 模型 / assistant"后面紧跟动作（说、回答、解释、认为、建议……），或用作句子主语开头；"Claude Code"不算 |
| P3 | 不用"他 / 它"指自己 | 正文没有"我"却有"他 / 它" |
| P4 | 不写自己的名字、不替自己定性别 | 出现配置的自称名字（`--self-name`）；出现"我是男 / 女的""作为一个男 / 女……" |
| P5 | 次数、频率不写 | "N 次""两三次""几次""多次""每次""每当""经常""总是""老是""往往""通常""频繁""屡次""反复""向来"；"第一次"不算（那是意外，该写） |
| P6 | 结论单独写、标明是谁下的 | 一句里有下结论的词（说明、意味着、所以、因此、可见、显然、证明、本质上、看来……）而同一句没有归属（我觉得、我认为、当时我、我判断、我意识到、她说、她觉得……） |
| P7 | 对别人的定性标明是谁的解读 | "她 / 他 / Joy（很、有点……）失落 / 生气 / 开心 / 不耐烦……"而同一句没有"我觉得、看起来、好像、似乎、大概、她说"之类 |
| P8 | 一件事一条 | 引用跨度大（跨过本段 40% 以上且 ≥ 30 行），或所引事件时间跨度 > 30 分钟且正文 > 200 字，或正文 > 500 字，或"另外 / 此外 / 然后 / 接着 / 后来 / 之后"这类转场词 ≥ 3 个且正文 > 200 字 |
| P9 | 用自己的话，不照搬模板 | 正文里出现经历模板的句式（"我调用了 X（"、"X 返回："、"（感知 · "） |

### 统计（不打分，给人看全貌）

- 条目数、段的行数、被至少一条引用的行占比（覆盖率）。
- 每条：字数、引用数、引用跨度（行）、所引事件的时间跨度、有没有 `felt`。
- 没被任何条目引用的行列出来（档号 + 前 40 字），方便人看"该写的有没有漏"。

## 二、要人判

看 `check.ts` 的报告 + 段的原文，逐条过：

| 编号 | 判据（catalog §二） | 看什么 |
|---|---|---|
| R1 | 一件事一条 | 机器的 P8 只是线索；真正判断是"recall 命中这一条时，读到的大半是不是相关的"。反过来，同一件事被切成几条也算不合格 |
| R2 | 具体：写动作和原话 | 有没有写出谁做了什么、说了什么关键的话；还是只剩"讨论了 X""完成了 Y"这样的提要 |
| R3 | 结论与事实分开 | 结论是不是单独成句、带着"当时我觉得"；有没有把自己的判断写成事实 |
| R4 | 按意外分配细节 | 第一次、和预期相反、被纠正的地方写细了没有；看了上文就知道下文的有没有一笔带过（而不是逐步复述） |
| R5 | 按后果分配细节 | 做了决定、改了东西、许了承诺、关系有变化、情绪强烈的——写细了没有；有没有漏掉 |
| R6 | 感受跟着事走 | `felt` 是这件事当时的感受，不是总结陈词、不是口号式的价值观；没有的就不写，不硬凑 |
| R7 | 视野只有局部 | 只写上下文里有的：没看到的大块工具返回、它不在场时到的消息，不该被当成经历叙述 |
| R8 | 时间与在场的人 | 读这一条能知道是和谁、大概什么时候（时间由档号带出，正文里不必重复；但人要写出来） |
| R9 | 口吻是它自己的 | 读起来像它自己记的，而不是第三方的报告（第三人称、只有打包好的结论）。这条最终靠 §四 的认同度验证：给它看两版叙述，看更认哪个 |
| R10 | 引用对得上 | 每条挂的档号确实是这件事的依据，不是随手挂几个凑数 |

## 三、不判的

- 文风、语气、长短、是否用比喻、是否幽默。
- 条目数多少——一段里有几件事就几条。
- 有没有写 `felt`——没有感受就不写。

## 四、提示词自查（`prompts/hot-write.md` v1）

每条判据在提示词里有没有对应的话。提示词只说"写什么、怎么挂档号"，不给范文、不规定语气。

| 判据 | 提示词里 |
|---|---|
| G1 upTo 原样交回 | "`upTo` 用给你的那个，原样传回" |
| G2–G4 有条目、有正文、挂档号 | "每条 `{ text, felt?, cites }`"、"每条挂上档号" |
| G5 引用落在本段 | "只能挂这一段清单里的" |
| P1–P3 第一人称、不以第三人称称呼自己 | "用你自己的话。称呼自己就用'我'" |
| P4 名字、性别 | 同上（只说用"我"，不提名字、性别，免得反过来暗示） |
| P5 次数频率 | "不写次数和频率……那是统计，系统会数" |
| P6 结论标归属 | "结论单独写，写明是谁的" |
| P7 对别人的定性 | "对别人的判断……也一样，写明这是谁的解读" |
| P8 / R1 一件事一条 | "一件事一条"，并说了为什么（翻到时读到的都是这件事） |
| P9 用自己的话 | "清单里的句子不用照抄"；别人的原话可以引 |
| R2 具体 | "谁做了什么、说了什么关键的话，而不只是'讨论了某某'" |
| R4 / R5 按意外、后果分配细节 | "细节按两样分配"两条，及"一笔带过不是丢" |
| R6 感受跟着事走 | "感受写在 `felt`……没有就不写" |
| R7 视野只有局部 | "只写你经历过的……不归你叙述" |
| R8 在场的人 | "在场的人写出来；时间档号带着" |
| R9 口吻是它自己的 | "这是你自己的记忆……措辞、长短都由你" |
| R10 引用对得上 | "这件事依据的是清单里哪几行" |
