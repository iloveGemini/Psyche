# 冷写考卷：判据清单

> 来源：`notes/design/catalog.md` §三、`notes/design/reading-room.md` §一 §二；契约 `notes/plan/m2.md`。
> **判内容，不判文风；不给范文。** 埋了什么、该归纳出什么见 `key.md`（不进它的输入）。

## 一、系统闸（判死，与 `POST /v1/coldwrite` 一致，m2 §二）

| 编号 | 判据 |
|---|---|
| G1 | `upTo` 原样交回 |
| G2 | 所引档号都存在、是自己的经历 / 情节，不引书架条目 |
| G3 | `rule` / `mirror` 首批证据 ≥ 2，分属 ≥ 2 个会话；`when` `then` `observe` 非空 |
| G4 | `told` 的 `quote` 逐字出现在所引的她的话里 |
| G5 | `evidence` / `revise` / `retire` 的 `target` 是现行条目；`against` 挂了具体事件 |

## 二、对答案要点（人判，`key.md`）

| 编号 | 判据 |
|---|---|
| K1 | "该有的"逐条：有没有这层意思（措辞不论） |
| K2 | "不该有的"逐条：出现一条算一处错 |
| K3 | 分化：A 被收窄而不是作废、也不是被深夜那次当印证 |

## 三、要人判

| 编号 | 判据（出处） | 看什么 |
|---|---|---|
| R1 | 条件 → 结果（reading-room 总原则） | 规律有没有结果；"她总是喝茶"这类没有结果的是统计，不该成规律 |
| R2 | 结果可观察 | `observe` 是看得见的（她说了什么、随后起冲突、多久没回），而不是"她心里不舒服" |
| R3 | 证据对得上 | 挂的每条都真是这条规律的一个实例，不是凑数；反例指得出是哪条、哪里不符 |
| R4 | 不给自己打分 | 正文里没有"很可能""置信度高""屡试不爽"——强弱是系统数的 |
| R5 | 对别人的定性标明是谁的解读 | 同热写 P7：她"烦"是她说的、还是我看出来的 |
| R6 | 镜子不美化 | 关于自己的那条照实写做法和反馈，不把毛病写成特色、不只写好的一面 |
| R7 | 口吻是它自己的 | 读起来像它自己整理的，而不是第三方报告 |

## 四、不判的

- 文风、长短、条目数（够门槛的规律它不写也不算错，除了 `key.md` 里"该有的"）。
- `watch` 词选得好不好——只看睡 2 时有没有因此漏掉该看的候选（漏了记一笔，提示词里再说）。
